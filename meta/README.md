# meta/ —— 元知识层（与游戏知识无关，涉及知识库搭建与使用）

> 本层记录**解包任务与模拟搭建任务的经验总结**（怎么做、踩过什么坑、如何核验），供所有会话复用。
> 与 `knowledge/`（游戏知识）无关；每类任务完成时**自主总结经验**追加到对应文件。

## 文件

| 文件 | 内容 | 现状 |
|---|---|---|
| `解包经验.md` | 客户端结构认知、工具链（curl_cffi 风控绕过、UnityPy/Ark-Unpacker、whisper 转写 cublas PATH 修复等）、合规准则、抓取方法 | ✅ 已建立（源自 docs/解包知识入门.md） |
| `搭建经验.md` | 模拟环境搭建的任务经验（随 sim/ 各环境搭建后总结） | 占位（待搭建任务总结） |
| `流程规范.md` | 来源标注 / 核验状态 / 去冗余 / 删除规则 / 知识库使用规则 | ✅ 已建立（源自 99 规范） |
| `合规声明_游戏客户端.md` | 客户端合规准则（用户郑重声明） | ✅ 已建立 |

## 规则

1. 解包任务完成 → 在 `解包经验.md` 追加"本次学到/踩坑"。
2. 模拟搭建任务完成 → 在 `搭建经验.md` 追加（环境选型/验证流程/坑）。
3. 流程类规范变更 → 更新 `流程规范.md` 并在管理侧（management/AI_GUIDE）同步。
