## 七、拼音规则（**无声调、小写连写**；T-066-b 建立）

**生成方式**：`ak\code\tools\glossary_build.py` 用 `pypinyin`（`lazy_pinyin`，无声调）批量生成，**人工兜底三层**：

| 层 | 变量 | 作用 |
|---|---|---|
| 整名兜底 | `PINYIN_OVERRIDE` | 官方名 → 拼音，整条命中时直接采用 |
| **词级兜底** | `PINYIN_WORD_FIX` | 只修"某个词"（如 `长臂→changbi`），**含该词的整名自动受益**（`“精准制导”长臂投手` 也一起对） |
| 留空待核 | `PINYIN_HOLD` | 拿不准 ⇒ 拼音列**留空** + 备注列写 `拼音待核`（**不瞎填**） |

**归一化规则**：只保留 `[0-9a-z]`（丢掉 `·`、`（）`、`“”`、`α`、`-` 等）；`ü` 写成 `v`（`薄绿 baolv`、`暴虐 baonve`）；
**原名不含汉字**的行（如 `12F`/`Castle-3`/`W`）拼音列填**小写原名**并备注 `非中文名`——它**不是**拼音，只为统一检索。
