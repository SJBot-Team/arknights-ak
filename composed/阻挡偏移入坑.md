## 目标

通过**阻挡偏移**把敌方单位的中点"挤"进坑格判定区，触发即死入坑。

## 机制链（推导）

```
① 阻挡判定：|干员中点 O − 敌人中点 E| ≤ 阻挡半径 0.7071，且每 3 帧扫描、优先最近、敌人可阻挡
② 偏移触发：|OE| < 0.5（且 >0.00001 不重合）时，E 沿 O→E 射线被推到距 O 恰 0.5（多敌时叠加修正向量）
③ 入坑判定：E 的新中点按四舍六入五成双取整 → 所属地块 == 坑格 → 即死
```

## 实现逻辑（伪代码，供 sim/draft 原型）

> 以下为 **2026-09-13 按代码核验后的完整版**（原版只覆盖单敌的 0.5 延长，多敌修正向量缺失）。

```python
def block_offset(A, B, all_blocked_by_A):
    """A = 阻挡者中点；B = 敌人中点；返回 B 被阻挡后应移动到的位置 F。
    依据：cv25694535 + BlockBalancer.CalculateBlockOffset (RVA 0x7C1050)"""
    AB = B - A
    d = length(AB)
    if d <= 1e-05:                       # 中点重合 → 不产生偏移（如 5-3 开局术士）
        return None

    # ① 长度延长：不足 0.5 则沿原方向延长到 0.5
    AC = normalize(AB) * 0.5 if d < 0.5 else AB

    # ② 累加修正向量（仅当 C 点 0.1 内存在其它已被 A 阻挡的敌人）
    corr = (0.0, 0.0)
    C = A + AC
    for D in all_blocked_by_A:            # ★ D 取"稳定阻挡位置"（stableBlockPosition），非实时位置
        if D is B:
            continue
        dDC = length(D - C)
        if dDC < 0.1:
            v = rotate90CW(A_to_D)        # 把 AD 绕 A 顺时针旋转 90°
            corr += normalize(v)
        elif dDC < 0.4:
            corr += (0.4 - dDC) * 50 * normalize(D - C)
        # dDC >= 0.4 → 无事发生

    # ③ 合成
    CE = normalize(corr) * 0.2            # 累加向量长度固定 0.2
    AE = AC + CE
    AF = normalize(AE) * length(AC)       # 长度设回 |AC|
    return A + AF                         # = F；F - B 即阻挡偏移

def try_block_offset_into_hole(op, e, hole, all_blocked):
    if dist(op.center, e.center) > 0.7071 or not blockable(e) or op.block_used >= op.block_cnt:
        return FAIL                       # 阻挡判定（每 3 帧扫描一次，多个候选取最近）
    F = block_offset(op.center, e.center, all_blocked)
    if F is None:
        return FAIL                       # 中点重合，无偏移
    # 敌人会在 0.2s 内被 tween 到 F（m_blockTween / BLOCKING_TWEEN_DURATION = 0.2）
    # F 同时被记为该敌人的"稳定阻挡位置"，供后续其它敌人的偏移计算取用
    if round_banker(F) == hole.coord:     # 四舍六入五成双取整 → 地块
        kill(e)                           # 进坑格即死
        return SUCCESS
    return PARTIAL                        # 已偏移未入坑（多帧/多干员重复）
```

**与旧版的关键差异**：
- 旧版写 `if d >= 0.5: return FAIL` —— **不准确**。|AB| ≥ 0.5 时只是不延长，仍可能因多敌修正向量而改变方向（此时 |AF| = |AB|）。
- 旧版忽略了**多敌修正向量**，而多敌挤位恰恰是入坑的常用手法。
- 新增"稳定阻挡位置"概念：**阻挡顺序会影响最终布局**，后计算者以先者的 F 为准。

## 玩家操作要点（几何推导）

1. 干员与坑的相对位置：使 **O→E 方向指向坑侧**（干员在坑的对面/侧位挡）
2. 敌人需先被压到 O 的 0.5 格内——单靠走过去阻挡不够（阻挡半径 0.7071 > 偏移阈值 0.5）；实战多用**窄路/堵路让敌人贴身停下**、多敌挤位、或推/拉/束缚先压近，阻挡偏移补最后一格
3. 坑坐标几何：敌人中点被推到边界线（x.5）时，坑坐标须为偶数才能判入（奇偶规则）
4. 适用敌人限制：可阻挡、可移动、地面（浮空/近地悬浮免疫坑）
