## 1. 逐篇要点

### 1.1 周期计时器 PeriodicTimer（cv44938490）★底层逻辑重点

**基本模型**
- 部署费用回复与 SP 自然回复的底层都是**周期计时器**：周期固定、冷却制。两个变量：剩余时间 + 周期时长。
- 启动：剩余时间 = 周期时长；每帧 −1 帧；≤0 时：剩余时间 += 周期时长 并触发一次事件（费用+1 / SP+1）。
- 暂停（锁费/阻回/费用或 SP 满）：触发推迟到暂停结束后。
- 周期为小数时（如回复速度 +10%）：上次爬多的剩余时间计入下次 → 微观间隔 ±1 帧波动、宏观均速与理论一致。

**重置并继承（回复速度变动时立即处理）**
- **部署费用：ResetButKeepProgress（按进度比例）**：新剩余时间 = 旧剩余时间 ÷ 旧周期 × 新周期。
  - 例：1/秒（周期 30 帧）剩 15 帧 → 变 1.1/秒（周期 27.27 帧）→ 新剩余 = 15/30×27.27 = 13.63 → 实际 14 帧后回费。
- **SP：ResetButKeepPastTime（按经过时间，下限 0）**：新剩余时间 = max(0, 剩余时间 − 旧周期 + 新周期)。
  - 例：1/秒剩 15 帧 → 变 1.6/秒（周期 19.75 帧）→ 新剩余 = 15−30+19.75 = 4.75 → 实际 5 帧后回 SP。
  - 下限 0 导致"冷却溢出"不记录到下一周期（即使溢出再多，下一周期也是完整的）。

**Bug 1：费用回复速度 = 0（稳定态萨卡兹术师结晶）**
- 回复速度为 0 → 周期时长 = 0（0 的倒数按 0 处理，避免除零崩溃）；进度值计算时周期为 0 → 进度直接设定为 1 → 剩余时间 = 1−1 = 0。
- 结果：**解除费用封锁后立即回复 1 点费用**（极短冷却后）——这正是 PRTS「稳定态萨卡兹术师结晶」页面备注"当前费用点冷却变为 0（锁链解锁后在极短冷却后立即增加 1 部署费用）"的由来。短时锁费反而可能加速回费。

**Bug 2：白面鸮 X 模组"+0.35/秒"提前回 SP**
- 白面鸮两个技力光环：全局光环（部署同帧生效）+ 碰撞光环（下一帧生效）；叠加策略 = **同类效果取最高**。
- 现象链路：部署白面鸮 → +0.3/秒 同帧生效 → 下一帧 +0.35/秒 挂上 → **瞬时回复速度 1.3 → 1.65 → 1.35**（叠加策略处理前数值累加 1.3+0.3+0.35=1.95？原文按 1.3→1.65→1.35 描述）。
- 周期计时器**每次变动立即重算**：1.3（周期 23.08，剩 4.08）→ 变 1.65（周期 18.18，剩 4.08−23.08 = −0.81 → 下限 0 → **SP+1 并重置剩余 18.18**）→ 变 1.35（周期 22.22，剩余 22.22）。
- 结果：**即使实际未达到 1.65 回复速度，处理逻辑仍以 1.65 的倒数为阈值，省略数帧提前回出 SP**。
- 同名 buff 微时序（鼓舞例子）：1 帧内两个鼓舞（60% 与 55%）**先同时生效再失去 55%**（D 选项），说明"同类效果取最高"是"先叠加后比较移除"的两步过程。

**可编程要点**
- 费用/SP 计时器：`剩余 -= 1帧; if 剩余<=0: 剩余 += 周期; 触发`；变动时按各自规则重算（费用按比例、SP 按经过时间下限 0）。
- 回复速度为 0 → 周期 0 → 剩余 0 → 解除即触发（模拟该敌人时须复现）。
- 技力/费用光环叠加是"数值瞬时变化链"，每次变化立即触发计时器重算 → 模拟需按帧处理 buff 生效顺序（全局 vs 碰撞光环帧差）。

### 1.2 迷彩与选择器/筛选器模型（cv48028109）

**选择器（Selector）vs 筛选器（Validator）**
- **选择器**：主动搜索可用单位（攻击索敌、瞬发技能索敌），绑定触发器；**受迷彩制约**。
- **筛选器**：被动处理碰撞到的单位（光环、藏品效果）；**不受迷彩影响**（除非特意排除迷彩）。
- 两者共享**目标选项（targetOptions）**参数集：
  - 阵营（同/对立/任意）；行动方式（可否对空）；**采用额外选项**（开启才受隐匿/无敌/孤立/禁疗影响；选择器必开；**迷彩论外**）。
  - 额外选项：无视敌我间可选性（隐匿/不可选中/地面规避/无敌；无敌伤害归零不在此处理）、无视友方间可选性（孤立）、无视医疗可选性（禁疗）、职业筛选（8 大职业/召唤物/装置）、仅无视特定异常（铅踝无视隐匿）、排除持有特定异常（深靛 2 排除束缚）。
- 选择器/筛选器实现上可互相模拟（画圆+选择器 vs 全图+筛选器），玩家视角无区别。

**迷彩能否被无视——不可预知（结论）**
- 判断步骤：①确定是选择器还是筛选器（主动=选择器、被动=筛选器）；②确认是否弹道（弹道无法再判断）；③非弹道判断攻击类型（溅射与否）；④即使全确定，选择器还有"**强制无视迷彩**"选项 → 结果不可预知。
- 大部分情况下（无特殊配置）迷彩可规避。
- 引用了 PRTS 选择器页面（m.prts.wiki/w/选择器）作为对照资料。

**可编程要点**
- 索敌模型分层：选择器（主动、绑定触发器、targetOptions 配置）+ 筛选器（被动、碰撞触发）；targetOptions 的"额外选项"是可选性（隐匿/无敌/孤立/禁疗/迷彩）的统一入口。
- 迷彩的可选中性由选择器配置决定（含"强制无视迷彩"标志），不能由表现反推——模拟时按各技能的选择器配置表驱动。
