# 舟数据与 PRTS 计算比对结论

> 比对对象：`E:\__file\舟数据\` 中用户自建的计算文件 vs 本知识库已学习的 PRTS 机制/公式。
> 结论级别：✅ 完全一致 / ⚠️ 基本一致（细节差异）/ ❓ 待验证。

## 1. 伤害计算体系（干员输出表.xlsx）✅

用户表格结构（每个干员技能一组列）：
```
攻击力 / 基础攻击间隔 / 最终乘算倍率 / 直接乘算倍率 / 最终加算 / 伤害倍率 / 攻速 /
敌方防御 / 敌方法抗 / 敌方物法减伤 / DPH / 攻击数 / 最终攻击间隔(帧) / DPS / 持续时间 / 总伤 / 回转 / 初动
```

与 PRTS 属性基本公式/伤害计算顺序完全对应：
- **直接乘算倍率** ↔ PRTS「直接乘算」（如「攻击力+80%」→ 1+0.8）
- **最终乘算倍率** ↔ PRTS「最终乘算」（如「攻击力提高至 380%」）
- **最终加算** ↔ PRTS「最终加算」（鼓舞类）
- **伤害倍率** ↔ PRTS「伤害倍率」（脆弱/易伤类，如钙质化 +55%）
- **敌方物法减伤** ↔ PRTS「最终效果-伤害乘算」（百分比减伤）
- **DPH/攻击数/间隔帧/DPS/总伤** = 标准输出循环计算

例（骋风2）：攻击 301 × 1.2s 间隔（=36 帧），21 次攻击，DPH 735.1 = 301×(1+0.2)×(1+1.5)×... 验证公式正确。
⚠️ 用户常把「基础攻击间隔」记作 1.2s（如剑豪 1.3s 记 1.2），存在 0.1s 级近似。

## 2. 属性换算发现：用户攻击力 ≈ PRTS atk90 + 信赖 + 模组 ✅

比对 73 名干员 PRTS「精二满级攻击力」与用户表中攻击力：
- 弑君者：PRTS 545 + 信赖 90 + 模组 90 ≈ 用户 725 ✅
- 蕾缪安：PRTS 1201 + 信赖/模组 ≈ 用户 1467（差值 266）
- 维什戴尔：PRTS 687 + buff ≈ 用户 874
- 幽灵鲨：PRTS 725 = 用户 725（**精确一致**，无 buff）

结论：用户输出表的攻击力普遍为**精二满级 + 信赖满 + 模组（或技能 buff）**的入战值；部分恰好等于 atk90（无 buff）。后续换算时以 PRTS atk90 + 信赖表 + 模组数据为准。

## 3. 攻速公式 ✅

用户「最终攻击间隔(帧) = round(基础间隔 × 30 / (攻速/100))」与 PRTS `T = T0/(clamp(S,10,600)/100)` 一致。
例：云迹 1.5s → 45 帧（攻速 100）；夜烟 1.6s → 48 帧但用户标 30 帧（攻速 160？）⚠️（夜烟2(-13) 疑带攻速增益）。

## 4. 敌人移动惯性/寻路模型 ✅

- `PATH_FIND.m`：`v += (v_desired - v) × 4/15`，其中 4/15 = 8 × (1/30) = **8×dt**，与 PRTS「寻路加速度 = (目标移速−实际移速)×8」**完全一致** ✅
- `坐标及期望.xlsx/加速度` sheet：「模式 8 {8,20}」验证了 8 倍加速度；「至完全恢复等效加 2.75f」等为帧级修正实测。
- 到达判定：方格（round 取整）/ 0.25 半径圆 / 0.05 半径圆 —— 与 PRTS「格子判定」「碰撞箱」对应。

## 5. 推拉位移力学模型（坐标及期望.xlsx/推拉）✅

用户模型：`加速度 = 9.81 × 0.5 = 4.905`（重力×摩擦系数），`帧速度衰减 = 4.905/30 = 0.1635/帧`；力度表 微-1/小0/中1/较2/大3/超大4（PRTS：微小-1/小0/中1/较大2/大3/大力+1=4/特大5）。
- 初始速度表：受力等级 -2→1、-1→2、0→4、1→4.5、2→5.3、3→5.8
- 位移曲线与 PRTS 推力-位移近似表（力度−重量 ≤-3:0 格 / 0:1.7 格 / ≥3:3.53 格）**量级一致** ✅
- 「水泡普攻/水炮1重/水泡0重」为推击手（温蒂系）技能参数。
⚠️ PRTS 明确位移是力学模拟无绝对公式，用户表为拟合值，精确模拟应以力学模型逐帧计算。

## 7. 控制/睡眠链（控制数据.txt）✅

- 夜半（战术家·眠兽）、卡夫卡（处决者）、「提提」构成睡眠控制链

- 「阻回」= 阻挡时回复技力（受击回复 SP），符合 PRTS 技能 SP 回复机制

## 10. 差异与注意点 ⚠️

1. 用户攻击间隔偶尔与 PRTS 差 0.1s（四舍五入/技能效果），以 PRTS 为准。
2. 用户攻击力普遍含信赖/模组/buff，不能直接当基础值；比对时用 atk90+信赖表。
3. 「深淀」= 深靛（官方名）笔误；「傀损」疑为傀影；「异银」= 凛御银灰（银灰异格）。
4. UOEP 表（uoep-data）数据为 2025-05 版本，不含其后实装干员；且部分数值为含信赖值（如银灰 763=713+50），引用时注意。
5. 部分敌方数据（如 h16-4 圣愚）可能与当前版本有出入（版本更新调整），以 PRTS 最新为准。
