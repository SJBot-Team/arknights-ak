## 3. 引用规则

1. **引用必带来源**：`来源：<PRTS页/B站cv/舟数据文件>（抓取日期）`。
2. **核验状态**：✅ 解包验证 / 🟡 待核验（K-###）/ 🔴 需 IDA——🔴🟡 结论不可当作已确认事实，用于模拟需注明假设。
3. 数据冲突时：本地解包验证 > ArknightsGameData > 社区实测 > PRTS 描述。
4. 基建内容仅了解，不作为模拟重点。
5. 待核验清单（K-001~024）在 knowledge/04/23，核验后回填并改状态。

## 4. 开展任务的建议路径

- **查机制**：knowledge/00~02 → 原文 → 核验状态。
- **核验数据**：data/ 找对应表 → code/tools 脚本 → 比对 → 更新 K 清单与核验状态。
- **搭模拟**：knowledge 引用的机制 → sim/draft 建原型 → sim/testing 对照 data → 通过后升 reference；经验写 meta/搭建经验.md。
- **解包**：遵守合规 → raw/client_res 备份上解读 → 经验写 meta/解包经验.md。
