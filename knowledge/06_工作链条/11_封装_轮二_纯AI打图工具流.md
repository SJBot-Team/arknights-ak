## 2. 尝试（按内容分组）

### 2.1 时间基准（打图侧的"地基"）
- **费用条视觉时钟**：ROI `(1736,806,1876,822)`、`bar_px = 140`；180px ↔ 30 帧 ⇒ **6px = 1 帧**
- **满条计数**：`totalElapsedFrames` 免疫"费用满/消耗"
- **战斗 HUD 门控**（三路全需）：A 卡片行、B 费用数字、C 敌人计数；**加第 4 路**「点击取消」红色信号
  解决"悬停操作态被误判为非战斗"（阈值 ≥0.40）
- **双通道互验**：费用条满 == 费用数字 +1（**18/18 完全相等**）
- **视频→游戏帧轴**：①费用**条填充** ②费用**数字**；实测 **1 视频帧 = 1 游戏帧**（本片 1X）
- **锚点**：用"部署造成的费用阶跃"钉帧（视频 621 ↔ 游戏 10；视频 4618 ↔ 游戏 411.3）

### 2.2 宏与输入通道
- 键鼠方案宏语义：`F` = 时停（按下暂停/松开恢复）、`W` = 划火柴、`S` = 0 帧选取、`E` = 卡帧对轴
- **实测关键差异**：`PostMessage` 的 F 键 = **暂停/恢复切换**；点**暂停按钮**会**取消悬停**，而宏键 F **不会**
- 输入通道矩阵：ADB tap/motionevent UP/swipe、SendMessage、PostMessage、真实鼠标拖拽（`SetCursorPos`+`mouse_event`）
- **子弹时间实测 5.0×**（基线 30.3 → 悬停 6.1 帧/秒）
- **过帧 = 两次暂停**（先暂停再过帧，过帧后处于**可读帧的暂停态**）

### 2.3 部署（**判据链最复杂的一环**）
- **两段式部署**（用户指点）：拖卡片→格 **松手**（进入朝向选择）→ 从格拖向朝向点 **松手**（提交）
- **朝向语义**：`DIR_DELTA` / `dir_to_px` / `deploy_px`
- **格点真源** `grid_px.py`：`x = 559 + 124.5·col`、`y = 502 + 138·(row−3)`；`self_check()` **14/14**
- 提交证据：**剩余可放置角色 8→7** + **费用 −8** + 卡槽消失

### 2.4 干员识别（五路尝试，最终定型）
| 路线 | 结果 |
|---|---|
| 头像模板匹配：三种固定几何 | ✗ NCC≈0 |
| 头像匹配：彩色互相关 + 滑窗 | ✗ 2/11 |
| 头像匹配：alpha 掩膜 | ✗ 2/11 |
| 头像匹配：HSV 直方图 | ✗ 1/11 |
| 头像匹配：多尺度模板 / 判别性扫描 | **✅ 编队页 11/11、战斗区 8/10（且能区分同费用）** |
| **名称 OCR**（借 MAA 思路，读详情面板） | **✅ '芬'/'芬'/None 三样本验证** |
| 结构性方案（费用升序 + `card_plan.json`） | ✅ 作为**快速定位起点**（不作判据） |

**名称 OCR 标定**：ROI **(20,250,150,330)** + **`--psm 6`**（`--psm 7` 无效）；原始输出含噪声 ⇒ 与候选名单做**包含匹配**。

### 2.5 导航与流程
- 导航状态机：`btn_drill` 信号分级（≥170 关卡页 / 110~170 编队 / <110 章节地图 / mean<60 加载）
- 退出战斗入口：暂停 → 左上齿轮 → 「I QUIT/作战完成度」→「放弃行动」（提示"恢复 0 理智"）
- 章节切换：靠**底部相邻章节卡片**（非滑动）
