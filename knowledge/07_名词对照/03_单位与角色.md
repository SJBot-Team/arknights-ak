## 三、命名规律（**用于反查 ID**）

- 干员 ID：`char_<数字>_<小写英文名>`（如 `char_123_fang`）；异格/形态加后缀数字（`char_1012_skadi2`、`char_1001_amiya2`）。
- 召唤物/装置：`token_<数字>_<英文名>`（如 `token_10020_ling_soul3`）；装置另有 `trap_*`（如 `trap_627_xb2amy`）。
- 敌人 ID：`enemy_<数字>_<英文名>`（如 `enemy_1000_gopro`）；同族用 `_2`/`_3` 后缀。
- **反查与排序都靠批量表**：`ak\glossary\01_干员.tsv`（1375）、`03_敌人.tsv`（1733）、`02_干员名别名.tsv`（927，含变体写法）。
- 单位 ID 文本的**排序**会影响待部署区顺序（规则见 `01b §12.11`）：
  按职业枚举 → 再按 ID 文本**逐字符**升序，**下划线 `_` 永远排在小写字母/数字前**。
- ⚠️ **纪律**：**不许按 ID 拼写猜中文名**（本轮已因此出过一次错：把 `char_4091_ulika` 猜成「乌莉卡」，实为 `U-Official`）。**要么查批量表，要么留 🔴。**

## 四、敌人命名规律与分类（**由 `ak\glossary\03_敌人.tsv`（1733 条）统计得出**）

- **ID 结构**：`enemy_<编号>_<英文名>`；同族的进阶形态用 **数字后缀** `_2`/`_3`：
  例 `enemy_1000_gopro`（**猎狗 / 猎狗pro / 狂暴的猎狗pro** 三形态同族）、`enemy_1007_slime`（**源石虫 / 源石虫·α / 源石虫·β**）。
- **等级三档**（官方枚举 `enemyLevel`，中文取自 `ak\glossary\05_枚举词典.tsv`）：
  `NORMAL = 普通`（755 只）· `ELITE = 精英`（720 只）· `BOSS = 领袖`（258 只）——合称 `ALL = 普通/精英/领袖`。
  ⚠️ **玩家说"boss"= 官方"领袖"**；`ELITE` 官方叫**精英**（不是"精英怪"）。
- **图鉴号**（`enemyIndex`，如 `O1`/`B1`/`FN`/`KST`）：按主题分系列的编号前缀，分布前几名为 `IB` 91 · `SD` 64 · `SM` 45 · `DU` 39 · `R` 36 · `DL` 34 · `AN` 33 · `SP` 31 · `LUD` 29 · `NAC` 25 · `OR`/`IL`/`SCI`/`SFR` 各 24（另有 45 条无号）。
  用途：想在 Wiki/图鉴里对号入座时用它，比中文名稳定。
- **移动类型**（`motion`）：`WALK = 地面` · `FLY = 飞行`；**攻击类型**（`attack_type`）：`NORMAL 普通 / SPLASH 溅射 / BUFF 持续 / ADDITION 附加 / NONE 无`。
- **实体类别**（`entity_category`）：`DEFAULT 默认类 / OBSTACLE 障碍物类 / TRAP_OR_ITEM 装置类`。
