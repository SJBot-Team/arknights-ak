## 三、使用方式（**给转写管线**）

```powershell
# 1) 导出热词（一行一个正词，供 whisper 的 initial_prompt / 后处理白名单）
python ak\code\tools\glossary_lookup.py --hotwords > ak\.tmp\hotwords.txt
# 2) 事后替换（人工确认后执行，逐条替换，不做全局正则）
python ak\code\tools\glossary_lookup.py --fixes
```

> **注意**：热词表**只放正词**（索敌、避障力…），**不放误写形**——把误写喂给模型反而会强化它。
