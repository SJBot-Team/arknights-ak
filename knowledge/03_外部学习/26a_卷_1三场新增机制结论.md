### 1.1 BV1GVeb6dEVw（0919 直播：失衡下的进墙/穿墙、阻挡与阻挡偏移、传送）

**A. 失衡与进墙/穿墙**

- 失衡位移**只在"落点"判定、无中间采样**：一帧位移的落点不在坑内即整帧飞过坑；蓝门同理（没有任何一帧落点落在 0.05 判定半径内即飞过）。｜BV1GVeb6dEVw [214.7]
- 物理碰撞箱间距分档：**>0.01 无判定**；**0.01~0.05 仅判定"碰到"**——阻止继续前进但**不向外弹出**；间距更深入时触发「射线检测」**预计算**，沿**弹出距离最小的方向**弹到间距 0.005（转写为"−0.05"，疑为 −0.005，**阈值存疑**）。｜BV1GVeb6dEVw [361.9] [501.8]
- 碰撞体分**连续形**（默认，走射线预碰撞）与**离散形**（只在落点判定后直接弹出）；离散形实测含**深池方正战士 / 深池卫队 / 深池影刀**（9、12 章）。**只有离散形能靠过高速度整帧越墙**；连续形只能靠"位置"进墙（失衡帧的最小弹出方向朝墙内）。｜BV1GVeb6dEVw [651.0] [2095.8]
- **失衡的弹出方向与失衡速度的大小/方向完全无关**，只取"弹出距离最小"的方向（上/下/左/右拉甚至原地失衡都可能向下弹）。根因是胶囊碰撞箱**上下不对称**（实体坐标上方 0.1 / 下方 0.3）→ 贴墙时向下只需 0.2、向上需 0.4，故多向下弹。｜BV1GVeb6dEVw [1481.6] [1504.6] [1602.4]
- **墙缝穿墙**：墙体按 1×1 **逐块独立判定**。把敌人停在两块墙之间的"格缝"上时，左墙要它向右、右墙要它向左 → 互相抵消使其留在缝内；此时**任何来源的失衡都能让它沿垂直方向穿出墙体**（两块墙只提供左右排斥、不磨损其垂直速度）。实测"右墙胜过左墙"，**作者亦不明原因**（猜与"旧格"有关，存疑）。｜BV1GVeb6dEVw [954.8] [2153.9] [2334.5]

**C. 阻挡偏移的完整算法（本场最实质的新增）**

- 阻挡偏移 = **「挤」+「转」同一套逻辑**：
  - **挤**：实体距离 < 0.5 的敌人被延展到 **0.5 圆边界**（已在 0.5 外则原地不动）。
  - **转**：仅当**预计算落点的 0.1 半径内**存在"更早被阻挡敌人的最终落点"才触发——0.1 内每个提供「垂直于（干员→该落点）方向、顺时针、模长 1」的权重；0.1~0.4 内每个提供**反向**权重 `(0.4 − 距离) × 50`；权重求和 → 归一化 → **模长缩到 0.2** → 与「干员→敌人连线」相加后**保持敌我距离**朝该方向旋转。
  ｜BV1GVeb6dEVw [3217.9] [3376.7] [3696.7] [3884.6] [4481.7]
- 时间实现：总时长 **0.2 s = 6 帧**，**起点到落点走直线**（不经中间点），每帧位移按**剩余时间²** 分配——与推拉的逐帧速度积分**不是**同一套算法。｜BV1GVeb6dEVw [4064.0]
- **旋转步骤只在 0.1 半径内存在其他已阻挡敌人时才发生**，否则**完全原地不动**（两怪相距 0.15 时后者不动；前者被打死后补位过来也不动）。｜BV1GVeb6dEVw [6772.9] [7010.9]
- 阻挡偏移期间敌人**可同时巡路**；也可能被传送"拽回/拽过"本不该越过的地方（**传送先发生也会被强行拉回**）。｜BV1GVeb6dEVw [4161.4]
- **入坑的格奇偶性**：斜对角、顺时针转 0.2 格处若能入坑即可入坑；**偶数格办法更多，奇数格不能用这种方式挤下坑**，往往要靠旋转类阻挡偏移。｜BV1GVeb6dEVw [8177.7] [8501.9]

### 1.2 BV1L4ez6oEcc（0920 直播：仇恨与排序）

**A. 仇恨计算的三级流水线（本场核心新增）**

- 仇恨排序是**三级流水线**：**仇恨过滤器 → 二次过滤器 → 嘲讽过滤器**（21/22 只记了"仇恨过滤器"一层）。｜BV1L4ez6oEcc [3866]
- **二次过滤器不是排序而是"交换"**：把符合其条件的单位与**当前第一位互换** → 结果**非单调**（本应更低的变高、更高的变低、中等的反而高于更高的）。｜BV1L4ez6oEcc [3959] [4031]
- **嘲讽过滤器是第二层独立过滤**（在二次过滤器之后无条件再排一次，只看嘲讽等级）。实例：负嘲讽的"矿工"（转写"邝公"）先被二次过滤器换到首位、又被嘲讽过滤器压回后面，最终锁到仇恨更低的另一单位。｜BV1L4ez6oEcc [3993] [4751] [4817]
- 过滤器**粒度**：一个仇恨过滤器 = 一套排序规则，**只有出现全新规则组合才新增**，一套可被所有同类索敌单位共用；「特殊索敌比仇恨优先」**不成立**（两者被同一过滤器同时考量，无优先级）。｜BV1L4ez6oEcc [1018] [1088] [1097]
- **钩锁**类过滤器确为"不看仇恨"型：**距离来源降序** → 拉最远的，同距离再按后续规则。｜BV1L4ez6oEcc [1113]

**A. 反射算法（"走进墙"的成因，21/22 完全空白）**

- **反射算法 = 阻止敌人进入不可通行地块的唯一设置**：若本帧落点地块 ≠ 出发地块 **且** 落点地块不可通行（**不判断移动前是否已不可通行**）→ 取「自身实体坐标 → 该地块中心」连线的**垂线**，把本帧**位移向量关于该垂线反射**，反射结果即实际落点。｜BV1qReG6XE6W [910]
- **反射只由角度决定、与速度无关**：正中心入射时任何速度都被大幅弹回；**边角大角度斜切反而被"送得更深"**（穿刺手靠传送前的惯性极斜切入 → 被反射送进墙内）→ **这才是"敌人走进墙"的成因**。｜BV1qReG6XE6W [1247] [1442]
- 进入不可通行地块会**取消/跳过所有可执行的"行动类"路径点**，只剩不可跳过的蓝门；此类「可被推拉进去的围栏地块」**官方自 11 章后已全部断供**。｜BV1qReG6XE6W [418] [497]

**B. 失衡物理（新增量化）**

- **失衡速度是等差衰减**（巡路是等比）：摩擦力 = 9.81 × 摩擦系数 0.5 = **4.905**（质量恒为 1）→ 每帧磨损 **0.1635**；
  总位移 = (首项 + 末项) × 帧数 / 2 ÷ 30（高斯求和）。初速 1 的总位移转写读数在 0.1825 / 0.1183 / 0.1185 间不一致（**存疑**）。｜BV1qReG6XE6W [4713] [4962] [4882]
- **退出失衡需三条件同时满足**：新速度 ≤ **0.1**、已超过**失衡保护时间**、无有效拉力来源（钩子不再勾着）；
  **失衡保护时间 = 0.1 s = 3 帧**。｜BV1qReG6XE6W [4795] [4836]

**C. 力度与推拉（新增量化）**

- **力度 → 速度是硬编码查表**（无计算公式）：有效力度 = `clamp(力度 − 重量, −3…3)` 后查表；
  力大小 = 表值 × **0.02** × `moveMultiplier`(**0.5**，与巡路位移共用)；
  力度文案 微小/小/中/较大/大 = **−1/0/1/2/3**，温蒂再 +1 → 力度 4（"超大力"，文案未写）。
  表值转写读数「0 1 2 4 4.5 3 5.8」(推) /「0 2 1 4 4 4 4 4 6」(拉) 明显漏读（**存疑**）。｜BV1qReG6XE6W [3366] [3455] [3492]
- **推力方向两模式**：**方向力**（= 干员部署朝向，**无视敌人位置**；见行者、初雪一、"来一"）与
  **镜像力**（= 来源→敌人坐标连线；小莫、施怀雅、"玻璃"）。｜BV1qReG6XE6W [3508] [3897]
- **方向力 → 镜像力转换条件**：夹角 **> 45°** 或距离 **< 0.25** → 转镜像力并**力度 −2**；
  **莱伊只 −1**；**见行者 2 技能与"初学一"不发生转换**（**身份存疑**）。｜BV1qReG6XE6W [3788] [3972] [3874]
- **45° 归属表**：正对角站位 **左上/右上算"上"、右下算"右"、左下算"下"、没有算"左"的**；
  推的方向与归属一致则正常，否则转镜像力（−2）。实测：右下目标朝下推不动、朝右正常（"站右不站左"即此）。｜BV1qReG6XE6W [4250] [4398]
- **推拉/失衡只提供速度、不规定位移** → 合力合的是**速度矢量**；同针同向叠加按 v² 放大（1+1→2 → **4 倍位移**）
  → **同针同方向合力最赚**；错针（差 1 帧）合力积分面积更小、明显吃亏。｜BV1qReG6XE6W [3169] [3272]
- 「有弹道推 / 无弹道推 / 手动撤 / 代理」的共同根本 = **同针结算顺序**：
  **有弹道推 = 命中帧"先命中后位移"**；**无弹道推 = 同帧位移流程已结算完之后才命中** → 当帧不位移、下帧才动（撤温蒂可复现）。｜BV1qReG6XE6W [5686] [5050]

**D. 碰撞与磕墙（新增量化）**

- **碰撞判定分层**：相距 **0.01** 内判碰撞，但**排斥挤开只在 0.005 内**发生
  → **0.005~0.01 是"判碰撞但不产生阻挡位移"的带**；沿墙根滑动（0.005 不重叠）不触发；
  "杰哥"刮人起飞与棘刺 3 拉线（长方形碰撞箱）均**不看 0.01**（老师明言仍不清楚哪些算多边形）。｜BV1qReG6XE6W [6943] [7766] [7093]
- **磕墙角**：垂直/平行的定义 = 「**圆弧圆心 → 墙角的连线**」为垂直（向墙里）、其垂线为平行；
  **只有接近墙的分量被磨损**，远离墙的分量不触发摩擦力；平行分量改写 **Vy − 0.4Vx**；**不可能同时磕两块墙**。｜BV1qReG6XE6W [7613] [7303] [7384] [7436]
