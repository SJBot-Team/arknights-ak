## 3. 对本知识库「模拟还原」目标的可用结论（可量化的规则列表）

以下规则均来自本批专栏原文（数值以「解包仅供参考」为前提）：

**A. buff 系统生命周期**
1. **对象池栈式复用**：buff object 失效后指针入通用栈（recycle），新建 buff 从栈顶取（allocate）；栈后进先出 → 事件回调持有的 buff 引用可能被复用换皮，必须区分「buff 实例」与「object/uid 槽位」。
2. **自然撤退事件链**（独行长路 bug 流程）：`撤回 buff（Tick 到最长时长结束）→ 清空自身 buffContainer（object 入栈）→ 触发单位结束事件 → 其它控制器创建新 buff（取到栈顶 object）→ RunActions 继续执行剩余步骤`——同一帧内 object 可被分配两次，UID 记录（m_buffUidMap）与实际持有者可失配。
3. **触发控制器 AdjacentAllyToggleChecker**（独行长路/单独行动者）：场上单位出生/结束时判定开/关 buff；实现为「创建/结束 buff」事件的机制存在 uid 失配风险，模拟建议按「光环式重算」实现。
4. **遍历缓存**：buff 事件遍历用「原列表的一次性快照」（cachedBuffer，只缓存一次）；遍历中增删不改快照 → 同帧多事件共享同一快照，新 buff 在当轮事件中不可见。
5. **延迟结束**：除清空 buff 池外，结束 buff 只标记+失效，正式移除/回收统一在各事件末尾执行 → buff 结束事件可能延迟到下一事件（如 OnBeforeAttack），跨事件时序敏感（令召唤物打自己、火球停攻案例）。
6. **清空 buff 池**：按缓存列表遍历结束/清空，可能结束不干净（贝娜叠防）；修复语义为「非 enumerator 逐个清」，并须防嵌套创建无限循环（A→B→A）。
7. **同名 buff 默认不叠加**（进光环/再进光环只表现一个，uid 覆盖丢失）——与 02 §7.10 同名状态一致。

**B. 光环能力（AuraAbility）**
8. 光环为被动（仅 attach/detach）；其 buff 全部为**无限时长**，结束由光环控制。
9. 进入/离开判定基于碰撞（OnTriggerEnter2D/Exit2D）；条件筛选 TargetValidator；登记 m_targetMap（实体→buff uid）。
10. **10 帧**更新一次 `_UpdateInvalidTarget`（处理隐身解除等）；目标离开范围必须同时从 m_invalidTarget 清理，否则范围外补挂 buff（原 bug 根因）。
11. 结束标志：`removeBuffWhenTargetLeave`（离开移除）、`removeBuffWhenAbilityDetached`（能力撤销移除）。

**C. 伤害与数值**
12. **法术伤害公式**：`MAX(0.01·Atk·倍率·MAX(0, 100−(1−穿透%)·MAX(0, 法抗−穿透值)), 0.05·Atk·倍率)`；0.01 实际按定点近似 `0.00999999978` 参与 → 伤害略低于理论；**死亡判定建议容差**（与 01 §12.8 一致）。
13. **元素伤害**：`伤害 = 伤害量 × (1 − 元素抗性 × 0.01)`，5% 保底同法伤；元素抗性 `EP_DAMAGE_RESISTANCE`、损伤抵抗 `EP_RESISTANCE`；**脆弱/干扰地雷类不对元素伤害生效**，不挑类型增/减伤可生效。
14. **敌人版凋亡损伤**：15s 元素免疫 + 每秒 800 无来源元素伤害 + 攻击力最终降至 50%（持续时间内线性恢复至 100%）。
15. **弹道攻击力两模型**：普通弹道每次命中取来源当前攻击力；`_useCachedAtkOnly` 弹道生成时缓存（无来源伤害的旧形态另有 `_transferSource=false` 问题）；行为替换（链术师每弹射重建伤害行为）会**重新缓存** → 实时更新。
16. **停顿时间配置**：普攻读 attack blackboard；瞬发技能读 skill blackboard；模组数据可覆盖 skill blackboard（同 key 跨技能串值）；durationKey 写死 `sluggish`。

**D. 词条/符文/职业掩码**
17. 词条对象筛选：实体类型（character/enemy/关卡选项/关卡数据/地图）+ selector（职业、部署位、实体、技能、地砖 id）。
18. **professionMask 10 位**：近卫=1、狙击=2、重装=4、医疗=8、辅助=16、术师=32、特种=64、召唤物=128、**机关 TRAP=256**、先锋=512；判定 `(mask & 职业) == 职业`；TRAP 机关（弩炮/冰晶）属 character 类型、敌方阵营。

**E. 敌人/状态机**
19. 推力 = 对 rigidbody 施力 + 状态机切 unbalance（激活碰撞箱、按摩擦力更新速度）；**reborn 状态不可直接切换**（需 force）→ 施力后不减速匀速位移。
20. **hp=0 隐藏机制**：不可被选中，已锁定目标丢失；重生血条回复时机由 `_hpRechargeRatio` 决定（霜星等 0.5 / 左手 0.2 / 爱国者 0.85 / 黑蛇二次 0 / 杰斯顿 1）。
21. 睡眠 = 无敌 + 无法行动（非眩晕，不触发「对眩晕增伤」类效果）。

**F. 模式/关卡结构**
22. 波次超时强制清场：`超时 → 场上敌人全部死亡 → 下一波`；完成 ≥1 波即胜利。
23. 熔岩裂隙地块：放置干员触发前方范围法伤（敌方额外受法伤提升）；朝暮之印改变经过敌军明晦属性；明晦之印赋予相同明晦（可切换、不可共存）；特殊阻挡条件需特定 buff 对。
24. 致残 buff：计时即死 / 进地下通道前即死 / 被主目标击杀时击杀者回固定 sp。
25. 弹药补弹：弹药数首次不高于一定比例时按最大弹药数一定比例补弹（**向上取整**）。
26. 明烛台技能 4：持续法伤次数 = 当前金币数量的一定比例（**四舍五入，至少 1 次**）；技能 2 基于目标最大生命%真伤、技能 3 基于目标攻击力%物伤。
27. 围棋 boss：白/黑/空点判定 → 提子 → 无气之子加（疑似秒杀）buff；周围 4 黑棋永晕；黑棋周围我方单位数提升其受物/法伤害。
28. 界园藏品叠加语义：弹药类/开启技能类「无限持续可叠加」与「不可叠加」两类；每阻挡一个单位物/法闪避**加法叠加**（有上限）；首个部署干员属性提升（含抵抗/阻挡数）。
29. DuoRangedAttack：继承单次弹道攻击，非首目标弹道变化，特定设定下对最后目标攻击 2 次。
