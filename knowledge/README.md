## 与其它层的关系

- 数据（`data/`）与原始素材（`raw/`）为本层的证据源；本层为它们做总结与交叉验证。
- 模拟环境（`sim/`）引用本层知识时，在 sim 环境 README 注明引用的知识条目。
- 元知识（`meta/`）记录知识库自身搭建/解包/核验的经验，与本层内容无关。
