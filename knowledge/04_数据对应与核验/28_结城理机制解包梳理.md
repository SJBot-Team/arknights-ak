### 2. 切换触发（技能使用 → 站场）
```
技能使用 → makoto_s1/s2/s3_trigger（buff 模板）
  ├─ 若已有 makoto_tr_undead → 无事（不死状态下不可重复切换）
  └─ 否则:
      makoto_tr（不死转化链）:
        mode=0 → can_trans_to_stand=1
        mode=3(S3_1) → can_trans_to_stand=1 + is_trans_to_s3_2=1
        can_trans_to_stand>0 →
          LogExtraBattleInfo("MAKOTO_CAN_TRANS")
          ConsumeTrySetHpZeroModifier   ← 免死关键（消耗“尝试归零”修饰）
          创建 makoto_tr_undead（UNDEADABLE + SKILL_NOT_ACTIVATABLE，不死+禁技能）
          按 skillIndex 触发 makoto[switch2stand_s1/s2/s3_1/s3_2]
```

### 3. 站场形态持续（makoto_standin）
- 切形态 = `OnRallyPointLikeReborn`（重部署点级复活）+ `ClearCharacterSp`（清 SP）
- `makoto_standin` buff：LIMITED，durationKey=makoto_standin_duration（SP_RECOVER_STOPPED + SKILL_NOT_ACTIVATABLE）
- `makoto_standin_t1_max_hp`：从 talent_1 黑板上限 → MAX_HP × 倍率（站场 HP 与天赋1挂钩）
- `makoto_assign_standing_time` / `makoto_switchend`：记录/回读剩余站场时间，按技能索引 SwitchMode
  （skill0→mode1、skill1→mode2、skill2→is_trans_to_s3_2?mode4:mode3）+ SwitchSkillRangeIdModeIndex

### 4. 切换回普通（makoto_switchend2normal）
- ClearAllBuffs（保留天赋/allout 组）→ SwitchMode(mode0) + `makoto_default_mode`
- `makoto_switchend2normal_blockcheck`：CheckBlocked（被阻挡计数）→ 施放 makoto_switchend2normal（mode=0 黑板上限）
- `makoto_switchend2normal_endcheck`：无 makoto_on_enter_normal 时触发 Allout_LoopEnd 动画
