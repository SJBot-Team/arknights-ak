## 二、★坐标映射（本轮确定，之前一直用错）

标定表的格子如 `D6`，其含义是 **`字母 = row 序号`、`数字 = col 序号`**，换算：

```
row = 字母序号 − 1        （A=0, B=1, C=2, D=3 …）
col = 数字 − 1
```

**交叉验证**（1-1 为 7×9；`.` 近战可部署、`^` 高台、`#` 不可部署）：

| 标定格 | (row, col) | 地图内容 | 结论 |
|---|---|---|---|
| **D6**（部署芬） | **(3, 5)** | 第4行 col5 = `.` | ✅ 近战可部署 |
| **D4**（部署月见夜） | (3, 3) | 第4行 col3 = `.` | ✅ 实测部署成功 |
| D1（敌人影子） | (3, 0) | `#` | ✅ 不可部署（敌人生成点） |
| G5（敌人影子） | (6, 4) | 第7行 = `#` | ✅ 敌人生成点 |

**同时与历史数据一致**：h12-4 的"令 C12 → (r2, c11)" 正是
`row = C(3)−1 = 2`、`col = 12−1 = 11` ✓ ⇒ **两处映射规则统一**。

（此前误用 `row = 总行数 − 行号`，导致"芬@D6"落到高台 ⇒ 部署失败。）

## 六、待查差异：费用恒定偏少

| 区间 | 模拟器 − 标定 |
|---|---|
| 0s | 0 |
| 3s ~ 13s | **−1（恒定）** |
| 14s ~ 18s | **−2（恒定）** |

规律：**每部署一次，模拟器费用比标定少 1** ⇒ 两种可能：
1. **模拟器部署扣费比实际多 1**（或首次费用起点差 1）；
2. **标定表的"该秒初始费用"口径**与模拟器的"整秒时刻费用"有半个 tick 的差异。

**注**：实测"帧10 部署芬后 费用=1.0"，而按 `10.33 − 8 = 2.33` 推算应为 2.33 ⇒
**模拟器扣的比 8 多**，需进一步核对**芬的实际部署费用**（标定表写 −8）
以及**费用增长与部署扣费的先后顺序**。
