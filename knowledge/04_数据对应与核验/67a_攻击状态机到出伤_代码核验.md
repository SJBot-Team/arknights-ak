## 一、一句话总览

**成立。** 「选中目标 → 实际出伤」是**两条互相咬合、但不同层的链**：

1. **状态机层（"可以攻击/现在攻击"）**：`Character.States.CombatState` / `Character.States.AttackState`（两个 `HierachyStateMachine.StateNode`）用 `_NextCombatOrExit 0x71CF80` / `_NextAttackOrExit 0x71B210` 做**节拍推进**；`m_nextEscapeTime // 0x18` 是逃生计时；`_GetTarget()` 拿目标，`_StartAttack()` 交给能力。
2. **能力层（"这一次攻击出多少伤"）**：`AbilityStandard.CastToTarget 0x34EF6A0` → `StartCastingInternal 0x34F7330` → `AbilityStandard.OnEvent 0x34F26A0` → **`ActionUtil.RunActions 0xC837C0`** → `ActionNode.Execute` → `Nodes.ApplyDamage.Execute 0xBB5A70` → `CreateDamageModifier 0xBB56C0` → **`BattleUtil.CalculateDamageByAtkNoSource 0x7BD540` / `CalculateDamageBySource 0x7BDB80`** → **`BattleFormula.CalculateDamage 0x3585890`**。

**关键修正（对 `67` 的收口）**：T-077 线索 `OnCastStart → ActionNode → CalculateDamage` **方向对、中间缺一环**。`AbstractBasicAttack.OnCastStart 0xA1E200` **本身不算伤害**——尾部 `jmp 0xA6DEF0`（`AbstractAnimatedAbility.OnCastStart`）只做动画/owner 取用；真正的 ActionNode 泵是 **`AbilityStandard.OnEvent 0x34F26A0`**。**`CalculateDamage` 没有任何一条调用链经过 `OnCastStart`**（§5.1 的 6 个调用者全在 `BattleUtil.*`）。

## 六、⑤ 弹道（Bullet）分支 vs 近战分支

**答：差别不在"算不算伤害"，而在"攻击力从哪来"——弹道走 `m_cachedAtk`（发弹时缓存），近战走实时 `atk`。**
