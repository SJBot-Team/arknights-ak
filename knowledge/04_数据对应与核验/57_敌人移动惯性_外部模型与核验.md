## 一、外部知识（★三处独立来源，结论完全一致）

| 来源 | 内容 |
|---|---|
| **① 舟数据玩家模型**<br>`ak/raw/zhoudata/text/通用__PATH_FIND.m` | ```matlab % 逐帧 1/30 s initialV = [0,0];               % 出生速度 0 v_desired = v0 * unitDir;       % v0 = 速度上限；方向 = 朝当前目标点 v = v + (v_desired - v) * (4/15);   % 速度向期望值指数逼近 pos = pos + v * dt; ``` 目标点到达判据有三种模式：**方格**（`floor` 边界内）/ **0.25 圆** / **0.05 圆**；最后一点用 `norm(pos−target) < 0.05` |
| **② PRTS 结论**（本项目知识库已收录）<br>`knowledge/05_舟数据/舟数据_与PRTS计算比对结论.md` §4 | 「**寻路加速度 = (目标移速 − 实际移速) × 8**」，并注明 `4/15 = 8 × (1/30) = 8×dt`，与 ① **完全一致** ✅ |
| **③ B 站机制录播**（本项目已收录）<br>`knowledge/03_外部学习/22_B站录播_神奇机制教学.md` | 「敌人每帧：由**巡路目标** + 自身坐标 + 理论移速生成**加速度** → 与上一帧速度（**惯性**）运算 → 本帧实际速度 → 位移」；**加速逐帧、减速即时**；<br>**加速度上限 `maxSteeringForce` = 10 或 100**（取决于单位设置），超限时**方向不变、模长收缩到上限**（R-029）；<br>**2.75 帧等效**：从 0 加速到 V 的位移 = 满速位移 − **2.75 帧 × V**（2.75 = 11/4，等比级数和）（R-027） |
| 本项目既有沉淀 | `knowledge/02_作战机制/24_常规关卡流程伪代码.md` §4：**惯性 + 加速度：地面 `steeringFactor=8` / 飞行 `=20`，`maxSteeringForce=10/100`** |

### 结论公式（每帧，dt = 1/30 s）

```
v_desired = v_max · û            （v_max = moveSpeed × level.options.moveMultiplier；û = 朝当前寻路目标点的单位向量）
a         = (v_desired − v) · steeringFactor        （地面 8；飞行 20）
|a|       = min(|a|, maxSteeringForce)              （地面 10；飞行 100；超限只收缩模长、不改方向）
v        += a · dt
pos      += v · dt
初始条件：v = 0（出生静止）
```

**等价形式（逐帧）**：`v ← v + (v_desired − v) × 4/15`（因为 `8 × 1/30 = 4/15`）。
时间常数 `τ = 1/8 s = 0.125 s` ⇒ 约 **0.125 s 达到 63%**、**0.375 s 达到 95%** 上限速度。

## 五、经验教训（写入"反重复清单"）

1. **实现与已沉淀知识脱节**：`steeringFactor=8`、`PATH_FIND.m` 的 4/15 早已在知识库里，
   但**"直线优先"分支**在重构时被写成"瞬时满速"，没有人回头对账 ⇒
   **凡是新增/重写移动分支，必须对照 `knowledge/02/24` §4 与本章的惯性模型**。
2. **不要用一处错误物理去补偿另一处**：本轮曾把"阻挡捕获距离"从 1.0 调到 1.5 来凑精度；
   补齐惯性后 1.5 不再需要，格判定（2.19）反而优于它（2.44）。
   ⇒ **拟合参数若需要偏离"自然值"很远，应先怀疑机制缺失，而不是继续调参**。
