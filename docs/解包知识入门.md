# 解包知识入门（明日方舟客户端与数据）

> 状态：**初步框架**，随学习深入补充。本会话已确认的信息以 ✅ 标注；未验证的以 ⚠️ 标注，需后续学习/实测确认。
> 目标：学习如何从游戏客户端提取数据（解包），并与 PRTS 数据互相校验，支撑「模拟还原游戏情景」。

## 1. 为什么需要解包

- PRTS 等 Wiki 的数据（干员属性、技能数值、敌人数据、关卡配置）最终来源于**游戏客户端的数据文件**（解包）与玩家**实测**。
- 解包能获得：精确数值（属性成长表、技能倍率、sp 需求）、关卡配置（波次/敌人/地图）、底层机制实现（代码逻辑），是编程模拟的最可靠数据源。
- 实测能验证：解包数据的解释是否正确（如 AOE 判定时序、位移力学）。

## 2. 明日方舟客户端结构（基础认知）⚠️

- 引擎：**Unity**（游戏逻辑为 C# + 部分 Lua 脚本）。
- 客户端数据通常打包在资源文件中，常见位置：
  - Android：`assets/` 目录（含 `gamedata`、`bundle` 等）。
  - 资源格式：Unity AssetBundle（`.ab`/`.bytes`）与文本表。
- **gamedata**（游戏数据表）通常包含：
  - `characters/`（干员数据：属性成长、技能、天赋）
  - `enemies/`（敌人数据：属性、技能、AI）
  - `levels/`（关卡数据：地图、波次、敌人配置）
  - `skills/`、`talents/`、`buffs/`（技能/天赋/Buff 定义）
  - `items/`、`recipes/`（道具与合成）
- ⚠️ 具体目录名、文件格式（JSON 明文 / 加密 / Lua 表）与版本相关，需在拿到客户端后实际确认。

## 3. 常见解包工具链（社区常用）⚠️

| 工具 | 用途 | 备注 |
|---|---|---|
| AssetStudio / AssetRipper | 提取 Unity AssetBundle 资源（模型/贴图/数据） | 社区通用工具 |
| uTinyRipper | 反编译 Unity 资源 | 同上 |
| ILSpy / dnSpy | 反编译 C# 程序集（`Assembly-CSharp.dll`） | 查看游戏逻辑实现 |
| Lua 解密工具（tolua） | 解 Lua 脚本 | 明日方舟早期用 Lua；2024 年引擎升级后有变化 |
| 7-Zip / 专用解包器 | 解 APK/IPA/资源容器 | 基础工具 |

⚠️ 具体工具与流程需针对当前客户端版本验证（2024-04 游戏引擎升级后资源格式可能有变化）。

## 4. 数据形态示例（本会话已确认的部分）

从 PRTS 抓取的干员页 `{{属性}}` 模板即对应解包中的角色基础属性表：
```
|攻击速度=1.6s        ← 攻击间隔（= 攻速公式中的 T0）
|部署费用=14→16       ← 首次→再部署费用（未精英化→精英化后）
|精英2_满级_攻击=542   ← 精二满级攻击力（属性成长表取值）
```
- 用户舟数据 `uoep-data.xlsb`（UOEP v0.3.0）即为一份**全干员数据表**（含信赖/模组/召唤物/天赋/使用场景标签），是解包数据的衍生整理，已导入 `ak\data\operators\`。
- PRTS 各技术页底部「数据源」链接（NGA 算法帖、B 站测试视频）是解包/实测结论的出处，学习时可直接引用。

## 5. PRTS 抓取方法（本会话已验证 ✅）

- MediaWiki API：`https://prts.wiki/api.php?action=parse&page=<页名>&prop=wikitext&format=json&formatversion=2`
- **必须携带** `Accept: application/json, text/plain, */*` 请求头（否则 CDN 403）。
- 干员页数据在 `{{属性}}` 模板；技能在 `{{技能}}` 类模板；敌人/关卡页类似。
- 动态页（干员一览/敌人一览）为 JS 渲染，wikitext 无数据，需逐页抓取或使用 PRTS 的 Cargo/语义查询。
- 本会话已实现脚本：`ak/scripts/fetch_pages.py`（批量抓取）、`ak/scripts/extract_operator_data.py`（干员属性提取）。
