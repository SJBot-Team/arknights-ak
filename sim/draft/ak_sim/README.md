## 设计约束

1. **逻辑与表现分离**：不加载动画（04/31 §3.2 结论）；只算数值与状态。
2. **可记录**：每帧切片（操作/血量/坐标/攻速/移速/随机数状态）可选择性落盘。
3. **可复现**：同 seed 同结果；预留 RNG 状态快照以便"给定随机数给出与客户端相同结果"。
4. **两端同轴**：轴表 JSON 同时被模拟器与打图执行器消费（`ak/code/vision/plugins/task/axis_runner.py`）。
