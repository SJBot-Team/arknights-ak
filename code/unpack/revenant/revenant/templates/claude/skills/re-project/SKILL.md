# Project conventions

The generated `re` skill carries everything Revenant knows about itself —
commands, tools, evidence rules, this project's outline. **This file is yours**
and is never overwritten: put here only what is true of *this game* and would be
wrong for the next one.

Things that belong here:

- Naming quirks of this title, once you have found them.
- Which classes turned out to be the real entry points for a subsystem — exact
  names, which is precisely what a reusable pattern cannot carry.
- Traps this specific target has already sprung on you.

Things that do **not** belong here: evidence tiers, the command list, anything
the generated skill already teaches. Those are generated, and a second copy here would
drift out of date exactly the way the old hand-written skill did.
