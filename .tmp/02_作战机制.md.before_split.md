## 1. 公共机制

### 1.1 隐匿（Invisible）
- 隐匿单位**无法被任何敌方能力索敌选中**；隐匿不算特殊能力（**沉默无法影响隐匿**）。
- 敌方隐匿特殊机制：**被阻挡后解除隐匿，不被阻挡 3 秒后重新隐匿**；我方干员不因被阻挡解除。
- 选中隐匿目标需要「无视隐匿」能力（反隐先决条件）：银灰 2 天赋「鹰眼视觉」、月禾 1「迹无」、极境、敌方技术侦察兵、反隐装置。
- 隐匿只针对敌方选择器；隐匿单位仍可被无来源伤害（毒雾、热泵通道）、部分无视隐匿的能力（星熊荆棘反伤、莫斯提马减速、源石祭坛范围伤害）选中。
- 干员入场动画期间短暂无法选中（非「不可选中」异常效果）。
- 相关可选性异常效果：**迷彩**（被反隐影响，溅射可无视）、**不可选中**（部署保护、狮蝎的假隐匿，不受反隐）、**无敌**（不被选中不受伤害）、**孤立**（无法被友方选中）、**禁疗**（全阵营治疗不可选中且治疗无效）。阻挡是最高优先级：被阻挡时强制可被攻击。

### 1.2 攻击范围 / 视野范围
- 子页面 `攻击范围`、`视野范围` 待抓取。攻击范围有攻击范围数值（如 1×1、3×3 等模板）+ 朝向。

### 1.3 职业与分支（程序意义）
- 角色类单位 = 八大职业干员 + **召唤物**职业（干员附属召唤物/陷阱）+ **装置**职业（关卡装置）。
- 程序上职业、分支、特性、性能**互相无必然联系**（例：傀影召唤物「镜中虚影」带处决者分支可吃攻速收藏品）。
- 敌人均为**无职业**单位：常规索敌中被视为所有职业，可被限定职业索敌选中；部分索敌会排除无职业（隐德来希萃血不能偷装置生命上限）。

### 1.4 部署费用与待部署区
- 部署/撤退/技能天赋会影响费用。撤退后再部署费用 ×1.5（第一次）/×2（之后）等规则见 `00` 笔记；费用影响待部署区排列。子页面 `部署费用`、`待部署区` 待抓取。

## 2. 伤害与 Buff

### 2.1 攻击 = 数据包（攻击属性数据）
- 一次攻击是包含伤害/治疗量与属性的数据包：伤害类型（物理/法术/真实/元素/治疗）、攻击类型（普通/溅射/持续/附加）、施加途径（近战/远程）、特性（非致命/环境伤害/生命流失）。
- **攻击结算流程**（顺序）：
  1. 来源 ON_CALCULATE_DAMAGE（生成 modifier，攻击倍率调整）
  2. 准备应用 modifier，检查是否被 cancel
  3. 目标 ON_BEFORE_APPLYING_MODIFIER
  4. 来源 ON_OUTPUT_MODIFIER（治疗倍率调整）
  5. modifier 为伤害 → 来源 ON_OUTPUT_DAMAGE（伤害倍率调整）
  6. 目标 ON_APPLYING_MODIFIER（受治疗倍率调整）
  7. On_Take_Damage/On_Take_Heal（取消隐匿/无敌下攻击、不可治疗单位的治疗、检查反伤/闪避/抵挡/护盾）
  8. 应用成功 → 目标 ON_APPLIED_MODIFIER
  9. 伤害 → 来源 ON_AFTER_OUTPUT_DAMAGE（成功造成伤害触发判定）
- 机制意外例：阿的固定伤害（类型 00）会被近战判定条件误判为近战（01&00=00 无变化 → 判为近战），触发因陀罗近战闪避；有弹道攻击固定类型 10（远程）。

### 2.2 生命值
- 归零离场（特殊情况除外）；内部处理复杂，子页面 `生命值` 待抓取。显示为 0 仍存活是小数四舍五入。

### 2.3 AOE 伤害判定
- 对攻击范围内每个**可被选中**的目标，按仇恨优先级逐个判定（我方受 AOE 按部署逆序）。
- **有弹道 AOE**（炮手）：先选单体目标/地点，命中后立刻选取范围内全体。
- **无弹道 AOE** 分两种：
  - **锁定人数**（强攻手）：抬手时选取（不超上限），前摇结束时结算——即使目标已离开范围（霜星冰环属此类）。
  - **锁定范围**（伊芙利特炎爆）：前摇结束时选取范围内全体并结算——目标跑出范围就打不中（也因此无法命中隐匿单位）。

### 2.4 Buff 判定与可选性
- 加 Buff：技能开启/部署时用 Buff 选择器选中范围内目标；期间新进入单位时补选；离开/技能结束/退场时清除（兜底机制使光环类 buff 基本永久）。2020-03-17 后有修改但大体仍适用。
- 隐匿单位一般无法被 Buff 选择器选中；能选中隐匿单位的 Buff 一定「无视隐匿/无法选择」。
- 经典意外：无敌状态进入光环 → 离开后 buff 无限持续（已修复）；位移前摇加 buff 可离开范围持续。

### 2.5 技能、天赋与沉默
- 敌人也有技能与天赋；敌方技能默认**可被沉默**（除非有沉默抗性或强制不可沉默，如暴鸰投弹）。
- 非技能形式的特殊能力默认不可沉默（若标注「受沉默影响时无效」则可被沉默）。

### 2.6 伤害计算顺序（Buff 结算顺序）
1. **面板与伤害（对攻击方 X）**：直接加算 `X1 = X + Σa` → 直接乘算 `X2 = X1(1+Σb%)` → 最终加算 `X3 = X2 + Σc` → 最终乘算 `X4 = X3 × Πd%`（「攻击力提高至 380%」「造成 600% 法术伤害」属最终乘算）。
2. **敌方属性（对防御方 Y）**：直接加算（防御-300）→ 直接乘算（攻击力-40%）→ 最终加算（攻速-20）→ 最终乘算（攻击力-40%）。
3. **最终效果**：伤害乘算（百分比相加，如减伤 100%）；伤害重写（如「需要 35 次伤害击倒」的特殊生命值机制）。

### 2.7 红字（Critical 显示）
- 最终伤害 ≥ 期望伤害 × 1.5 显示红字（就近取整显示）。期望伤害不考虑：防御/法抗贯穿、后置增益（脆弱等）、伤害重设、屏障、特殊生命值机制；无敌时 ×0。
- 0 伤害也显示红字（0 ≥ 0×1.5）。被闪避的潜在红字显示黄字 MISS。强制红字技能无视规则；被屏障/护盾挡下转蓝字/黄字 BLOCK。
- 缓存攻击力（如老鲤）以攻击力为期望，高防目标更难出红字。

### 2.8 就近取整：四舍六入五成双
- 底层取整方式（banker's rounding）。子页面 `就近取整` 待抓取。

### 2.9 伤判效果与生命流失
- 伤判效果（闪避/格挡/护盾/屏障等的统一判定框架）见子页面 `伤判效果`。
- **生命流失**：计算防御/法抗后**跳过所有结算与伤判效果**的伤害；不触发反伤/受击回复；不受脆弱/庇护影响；无法被闪避/格挡/护盾/屏障规避；默认伤害类型为**真实**（标注物理/法术流失时会受对应抗性衰减）。

### 2.10 符文（Rune）
- 关卡先行修改机制（突袭条件、危机合约词条、活动机制），通过预定义值修改地图/干员/敌人/方格等几乎所有内容。
- 实现上可为关卡引入 Buff：直接属性修改（符文运算，见 `01`）、修改技能/天赋数值、环境级 Buff（集成战略收藏品等）。
- 符文 ≠ 符文运算（后者是数值算法）。

## 3. 敌人类单位行动与坐标（模拟寻路的核心）

### 3.1 行动基本原理
- 寻路使用 **SPFA**（最短路算法）；理想状态下**所有敌人始终选择最短路径**；相同路程选缩短空间距离的路线。
- 类障碍物地块有寻路代价：普通 1000；**地穴 1,000,000**（2023-02-14 修复后，「敌人自动进坑」成为历史）。
- 飞行敌人走飞行寻路（不进「飞行不可通行地块」）；地面敌人走地面寻路（不进围栏/高台等）。侵入点与保护目标点属于可通行地块。

### 3.2 路径点事件指令（Pathpoint）
| TypeID | 事件 | 说明 |
|---|---|---|
| 0 | MOVE | 移动到指定位置（含 Position + ReachOffset 偏移量；偏移量影响贴墙走等） |
| 1 | WAIT_FOR_SECONDS | 停驻（到位置后计时） |
| 2 | WAIT_FOR_PLAY_TIME | 停驻（全局计时） |
| 3 | WAIT_CURRENT_FRAGMENT_TIME | 停驻（当前兵团开始后计时） |
| 4 | WAIT_CURRENT_WAVE_TIME | 停驻（当前波次开始后计时） |
| 5 | DISAPPEAR | 进入传送（消失状态：无敌透明，被阻挡时解除阻挡、停止攻击） |
| 6 | APPEAR_AT_POS | 离开传送（瞬移到指定位置） |
| 7 | ALERT | 警报（多维合作） |
| 8 | PATROL_MOVE | 巡逻（路径点不消失，闭合循环移动） |
| 9 | WAIT_BOSSRUSH_WAVE | 引航者试炼休整 |

- 敌人起点在方格正中心，终点判定点为终点格中心小圆。
- 完成全部行动指令 → 模型消失 → **立即扣除对应目标生命值**（除非 `isUnharmfulAndAlwaysCountAsKilled` 只计已处理不扣命）并触发警报；地图上存在至少 1 名「必须处理的敌人」且目标生命未耗尽则关卡不结束。
- 「非首要目标」属性敌人无需被处理即可结算通关（铁砧、破片等）。
- 传送修复：0.066s（2 帧）内位移 >4 格不再被识别（曾可用「正比于距离的真实伤害」巨量伤害）。

### 3.3 地穴
- 判定点进入地穴格的地面敌人**立即判定死亡**（一次）；近地悬浮被控制解除时也会判定。
- 判定死亡后针对其的攻击（含位移/眩晕等附加）全部无效。
- 浮空（艾丽妮引入的「浮空」）可抢在死亡判定前把敌人变空中单位而免死。
- 即死判定在「进入地穴时」触发：若进入时未判定（如浮空），敌人可站在地穴上。

### 3.4 行动受阻（返航）
- 敌人进入不可通行地块 → 避障力作用缓慢移出（避障力 = max(实际移速/理论移速, 0.5)，与寻路加速度 −0.5 平衡，以约 0.0625 格/s 移出）；停驻时间相应扣除；传送指令改为原地触发。
- 地块上有角色/装置时正常攻击与阻挡判定（阻挡数 0 不影响返航）。
- 找不到前往下一目标点路径 → 永远「迷失方向」。

### 3.5 闪现（弑君者类）
- 判定：当前指令是「行动」；判定点与目标点连线距自己 1.5 格处为不可通行地块 → 沿连线方向移动 1.5 格并短暂不可阻挡。
- 无前摇，15 帧过程 + 10 帧后摇，期间无敌；跳过被跳过的停驻点指令。地形巧合可「后撤步」。

### 3.6 敌人模型
- 我方干员碰撞体积基本为半径 0.25 格圆形。
- 判定类型：**碰撞箱碰撞**（最常用，索敌/抬手）、**中点判定**（阻挡、酒神 1 天赋）、**格子判定**（坑、睡眠范围、地雷、标记；坐标 round 取整）、**全图**。
- 空降阻挡偏移：向有敌人的格子空降时敌人坐标被偏移到 0.5 半径圆边界（沿干员圆心指向敌中心方向）；方格正中心敌人（敌我距离 <0.00001）不偏移。
- 多名敌人被同一挡多干员阻挡时，后阻挡者产生 ≤0.2 距离的旋转偏移。
- 朝向：敌人只有左右朝向；移动时面朝移动方向（以摄像机 POV 为准）；攻击时先面向目标；受推力失衡面向来源。
- 【弱点】机制（落叶逐火）：与朝向相关的伤害判定（正/背面伤害，以敌人所在格所在列/行为界）。

### 3.7 波次结构（模拟出兵）
- 关卡敌人分 **Wave（波次）→ Fragment（兵团/碎片）→ Action（小队/动作）→ 单个敌人**。
- 小队动作指令：SPAWN（召唤出生）、PREVIEW_CURSOR（显示路径线）、STORY/DIALOG（剧情）、PLAY_BGM、DISPLAY_ENEMY_INFO、ACTIVATE_PREDEFINED/TRIGGER_PREDEFINED（预部署单位生效）、PLAY_OPERA、BATTLE_EVENTS、WITHDRAW_PREDEFINED、E_NUM。

### 3.8 地块（tile）
- 地块属性：**tileKey**（种类：禁止部署、地面/高地、保护目标点、侵入点、传送出入口等）、**heightType**（高度：低/高）、**buildableType**（部署类型：不可部署/仅近战/仅远程/全部）、**passableMask**（通行类型：无/仅飞行/全部）、**playerSideMask**（多维合作）、**AdvancedBuildableMask**（地形标记：深水、涨潮、黑夜等）、`isNonebuildableLike`（辞岁行起，「不可部署字格」只允许特定单位部署）。
- **tileTypesMask**（地形类型分类）：END 终点类（保护目标）、START 起点类（侵入点）、HOLE 坑洞类（地穴）、FAKE_HIGHLAND 假高台类、RESPAWN_ABNORMAL 不适合作为移动目标类。
- 地图外观（模型贴图）与程序定义无关：能不能通行/部署与「长什么样」无关。
- 部署类型与地块高度无关（玉门天灾工事 = 远程位低地）；关卡条件改的是地块部署类型而非干员；艾拉（Δ 模组）、Mon3tr（3 技能）可改自身部署类型。
- **地形 TAG**：地图属性标签（不是地块地形），用于锡兰水地形天赋等；活动限定天赋常依赖（摩根、凛视等）。

## 5. 代理运行与判定机制

### 5.1 基本机制
- 代理 = 复现录制的操作序列；**每个关卡有固定随机数种子**（关卡种子 + 时间种子 → 随机数序列），理想状态下整个流程随机数串极其稳定。
- 玩家操作代理原理：保存最后一次的部署/撤退/手动技能/装置操作（按帧序列）→ 无法复现的操作进**存储序列**，每帧扫描（条件变化：费用/部署人数/存储序列变化时）执行可完成操作。
- 存储序列非空 → 黄标「检测到失误风险」；敌人进点扣命 → 立即红标「请求人工接管」。

### 5.2 代理失误原因
1. **干员能力变化**（主因）：费用不足（精 1 +2 费卡费）、技能 SP 需求降低/SP 供应变化、推拉力度提升、过早击杀回费/SP 来源、模组默认变更（莫斯提马 Y 模减速全场）、随机判定天赋占用随机数轴等。
2. **丢帧**：30 FPS 帧率；丢帧导致效果释放失败扰乱时间轴（二倍速代理更易翻车）。
3. **版本更新**：底层机制/敌人逻辑修改（霜星掀地板目标、浮士德紫箭频率等）。
4. **特殊怪物能力**：打击操作层的敌人（稳定态萨卡兹术师结晶等），代理不继承设备信息故无法用操作层操作规避。

### 5.3 随机事件的代理原理（随机数轴）
- 随机数序列决定所有随机判定：闪避/暴击、艾雅法拉乱火、华法琳不稳定血浆对象、霜星掀地板、W 盒子、阿天赋四选一、雷蛇/华法琳充电对象、空安可结果等。
- 随机数序列随代理保存并在衍生作战中沿用 → 可用其他干员「用掉」不想要的随机数（经典操作：用别的判定消耗失败值，让目标判定命中/闪避）。

## 6. 对模拟实现的关键提示
- 寻路：SPFA 最短路径 + 地块寻路代价（普通 1000 / 地穴 1000000）+ 移动偏移量；敌人按 MoveMultipiler(0.5) × 移速每帧移动。
- 伤害结算顺序严格：生成 modifier → 检查 → 反伤/闪避/抵挡/护盾 → 应用 → 触发判定。
- AOE 分弹道/锁定人数/锁定范围三种实现。
- 代理/随机数轴：关卡固定种子 → 可复现随机序列（对「找解」计算极其重要：给定操作序列可确定结果）。

### 7.1 索敌的概念（目标选择总规则）
- 一般规则：任何可攻击单位（敌我皆然）攻击进入其攻击范围的**前 n 个单位**（n = 攻击目标数）；能近战的单位更优先攻击**自己正阻挡着**的敌人。
- **敌方仇恨优先级**：`阻挡 → 特殊优先级 → 仇恨值（更容易被攻击 → 第二优先级 → 最后部署的目标 → 不容易被攻击）→ 最早出现`。
- **我方索敌优先级**：`阻挡（近战限定）→ 特殊优先级 → 第二优先级 → 仇恨值（更容易被攻击 → 剩余路径最短 → 不容易被攻击）→ 最早出现`。
- 阻挡：
  - 大部分情况下敌人被阻挡即可向阻挡者攻击，**无论是否处于自身攻击范围半径内**；部分敌人被阻挡时采取不同攻击。
  - 我方近战（含重装要塞分支）常态可并优先索敌自己阻挡的敌人（即使未走入攻击范围）；我方远程干员通常**不**优先攻击自己阻挡的目标（目标在身后可能因不在攻击范围而无法攻击）。
  - 随机索敌/不考虑阻挡的攻击方式等特殊情况可无视阻挡状态攻击。
- 特殊优先级（来自干员自身或其技能的索敌算法，通常最高，仅当所有目标参考数值相同或均不满足/满足条件时才可能因其他因素改目标）：神射手优先攻击防御力最低；爱国者毁灭形态攻击半径 20 内距离自身最远的高台干员等。
- 第二优先级（在原索敌上额外一次排序导致的优先级调换；**对干员而言比嘲讽更有效，对敌人而言嘲讽更有效**）：速射手优先攻击空中单位；射手/狂徒/泥岩小队掷能者优先攻击 XXX 等。
- 更容易/不容易被攻击：增减目标**嘲讽等级**；1 级嘲讽等级≈部署/出现了极长时间的干员。例：我方 拜松深化阵线、夜莺幻影、泡泡挨打；敌方 游击队盾卫（容易受攻击）、爱国者行军形态（嘲讽 +2 级）；我方降嘲讽 伏击客特性、W 天赋后；敌方降嘲讽 红标渗透者（嘲讽 −1 级）。
- 最早出现：单位出现/部署时间；**不存在「同时出现」**（哪怕同帧也有先后）；前面排序均无法区分时选更早出现的。
- 不适用仇恨值的索敌：
  - 生命值**百分比**基准（苦艾、始海穿刺者）：生命值相同则永远攻击更早出现的（哪怕始海穿刺者理应攻击最后部署的干员）。
- 嘲讽等级的等效转换（数值基准索敌中 1 级嘲讽 ≈ 如下数值）：
  - 攻击力基准（「左手」泰特斯·白杨降攻索敌）：**1 级嘲讽 ≈ 1 点攻击力**。
  - 防御力基准（守林人等）：1 级嘲讽 ≈ 0.1 点防御力。
  - 生命值基准（W「D12」）：1 级嘲讽 ≈ 0.1 点生命值。
  - 重量等级基准（早露全部索敌）：1 级嘲讽 ≈ 0.1 级重量。
  - 最大生命值基准（鼠王）：「唱沙」1 级嘲讽 ≈ +1 点最大生命值；「沙暴」1 级嘲讽 ≈ −1 点最大生命值。
- 阿的两个爆发剂：索敌中正前方角色嘲讽权重非常高，正前方友方虽为特殊优先级，阿仍会攻击更容易被攻击的目标。
- 阻挡的敌人强制攻击：敌人被干员阻挡时会强行无视对方可选性发动攻击（隐匿/不可选中/无敌单位仍会被阻挡的敌人选中并攻击，例：愚人号阻挡数 +1 的不可选中召唤物被攻击）；反之敌方被我方阻挡时需解除自身隐匿一段时间，否则我方即使阻挡也无法攻击它。
- 攻击前摇锁定：前摇锁定目标后，当次攻击**大部分情况下不因目标可选性或位置改变**（白金射 7 格外目标、送葬人 3 次攻击取消的「反常」现象）。

### 7.2 攻击范围
- 攻击范围是物理碰撞体：**1×1 方块拼成的多边形**或**半径确定的圆**；每个攻击/技能能力通常只有一个碰撞体。多边形由单位数据中的「攻击范围 ID」自动生成；圆形用写死的半径（通常为 1）。
- 按用途分：**青色攻击范围**（治疗相关）/ **橙色攻击范围**（攻击相关）；Boss 巨型地块的红色条纹不属于攻击范围。条纹显示始终以格为单位（圆形范围也显示为方形橙色范围）。
- 常见范围称呼（模板）：
  - **面前一格**（ID 1-1）：所在格 + 部署朝向正前方 1 格（共 2 格）。
  - **身后一格**（ID b-1）：所在格 + 朝反方向 1 格（共 2 格）。
  - **周围四格**（ID x-5）：曼哈顿距离 ≤1 的所有格（共 5 格）。
  - **周围八格**（ID x-4）：切比雪夫距离 ≤1 的所有格（共 9 格）。
  - **周围十二格**（ID x-1）：曼哈顿距离 ≤2 的所有格（共 13 格，德克萨斯剑雨俗称「剑雨范围」）。
  - 官方文本可能忽略本格，站内必要时注明是否含本格。
- 可拉伸（受「攻击距离」属性影响）：
  - 多边形：每 1 点攻击距离令方块向正前方拉伸 1 格；**重叠部分无效** → 相当于向部署方向前方多一列。
  - 圆形：半径增加等同攻击距离属性的量。
  - 不可拉伸的范围（多边形/圆形）始终不受攻击距离影响。
- 圆形范围另可选 `scaleble`：启用时设定半径 × 默认半径；未启用时设定半径覆盖默认半径。

### 7.3 视野范围（AttackRangeTiles）
- 视野范围 = **人为规定的显示范围 `||` 攻击触发器的范围**（`||` 为逻辑或，**显示范围优先于触发器范围**）。
- 攻击触发器（「默认范围」）类型：
  - `SelectorTrigger`：范围内有目标则触发攻击/治疗行为。
  - `NeverTrigger`：永不触发攻击，范围始终为 0（不存在）。
  - `AlwaysTrigger`：总是攻击，范围始终为 1（全屏）。
  - 其他类型。
- 显示范围例：安比尔「雷达定位」开启后攻击全场但点击安比尔攻击范围无变化。
- 通常视野范围与攻击范围一致；技能可改变视野范围（铃兰「狐火渺然」、澄闪「澄净闪耀」= NeverTrigger → 丢失全部视野范围，选中后所在格也无斜条；安比尔斜条不消失 = 人为显示范围）。
- **技能范围 ≠ 攻击范围**：瞬发/目标选取类技能的范围是目标选取范围，非攻击范围扩大。
- 用途：生息演算「迷雾」、主线第十二章「鉴定」、可露希尔范围扩大逻辑；长夜临光「视野」**不使用**此系统；挽歌燃烧殆尽使用改良版「有效视野」。
- **盲区**（树丛/盾与墙/旧日之火等遮挡视野装置）：
  - 判定（存疑）：将我方单位所在格与场上所有地块中心及中心周边两个点逐一连线，若任一连线穿过存在可遮挡视野单位的地块（忽略目的地地块上的此类单位）→ 该地块记为盲区；场上遮挡装置数量增减时所有单位盲区立刻更新。
  - 我方单位无法主动选择位于自身盲区中的单位（**格子判定**）作为攻击/能力目标（类似反向迷彩）；攻击范围内盲区地块标记为灰色。
  - 盲区不改变「视野范围」本身（不影响鉴定进度、生息演算点亮地块等视野相关机制）。
  - 直接选择目标的能力必须目标不在盲区中；不直接选择目标的能力可绕过盲区：光环效果（逻各斯殁亡斩杀、铃兰狐火渺然）、特殊弹道（魔王「明日遥远不及」微尘）、强行选择指定单位（凯尔希治疗 Mon3tr、远牙「同盟支援」）、不进行来源结算的效果（炼金师炼金单元）。复合技能分别判定（塞雷娅钙质化：减速/法术增伤生效、攻击/治疗受阻）。
  - 利用他人攻击范围的能力按**自身**盲区判定（维什戴尔被遮挡但魂灵之影不在盲区 → 仍可攻击；新约能天使轰炸由新约能天使选取目标）。
  - 铁钳号·原型机非我方单位，无盲区，但仍能提供有效视野。
- **有效视野** = 视野范围 − 盲区的剩余地块；环境有效视野 = 所有角色类单位有效视野范围之和（挽歌燃烧殆尽中所有「攻击范围/视野」描述均指该总和）。

### 7.4 推与拉（位移力学）
- 敌方单位受到任意来源的力且 **受力大小 > 0** → 进入**失衡（UNBALANCE）状态机**。受力等级 = 力度对应表与目标重量之差；方向性分**径向**与**方向**（方向力在满足条件时变为径向力）；作用时间见下。
- **推力（推开）**：
  - 方向性修正：
    - 沿设定方向推动 = **方向力**，不修正（常见推击手特种干员推力）。
    - 沿干员→自身中心点射线方向推动 = **径向力**，不修正（其余推力；薄绿 2「聚能涡旋」的「拉力」也是径向力）。
    - **特殊修正**：方向力下，若目标与干员连线与部署方向夹角 **>45°** 或距离 **<0.25 格** → 修正为径向力且**受力等级 −2**（部分技能干预此修正，如见行者、莱伊，以干员描述为准）。
  - 作用时间：**瞬间**（可视为目标得到 实际受力×1s 的动量）。
  - 力的大小：查表得「列表值」，实际受力 = 列表值 × 0.01；初速度由 FΔt = mΔv 计算，之后目标在平面上匀减速至停止。
  - **推力表**（受力等级 / 列表值 / 受力 N / 初速度 / 理想移动距离·弹道 / 理想移动距离·特效）：

    | 受力等级 | 列表值 | 受力(N) | 初速度 | 弹道距离 | 特效距离 |
    |---|---|---|---|---|---|
    | ≤−3 | 0 | 0 | 0 | 0 | 0 |
    | −2 | 100 | 1 | 1 | 0.11825 | 0.08492 |
    | −1 | 200 | 2 | 2 | 0.4403 | 0.37363 |
    | 0 | 400 | 4 | 4 | 1.6958 | 1.56247 |
    | 1 | 450 | 4.5 | 4.5 | 2.13705 | 1.98705 |
    | 2 | 530 | 5.3 | 5.3 | 2.95013 | 2.77347 |
    | ≥3 | 580 | 5.8 | 5.8 | 3.52392 | 3.33058 |

  - 弹道类推动（温蒂 2/3、阿消 1/2）比特效类（食铁兽 1/2、见行者 1/2）同力度下推出更远：命中帧时弹道类多一帧以初速度进行的失衡位移。
- **拉力（拖拽）**：所有拉力都与一名拉动者与一个弹道绑定（有时弹道隐藏/绑定动画）。
  - 作用时间：默认 1s；**受力等级 < −1 时改为 0.5s**。只考虑**弹道力度**与目标重量；肉鸽藏品神力、特殊地形特种战术点提供的**基础力度**加成不参与时间结算；歌蕾蒂娅 Y 模组、雪雉天赋的**弹道力度**加成正常参与。
  - 拉力起点：大部分为干员前方 0.5 格；歌蕾蒂娅 3 技能聚怪部分指向开技能时标记的敌人坐标；锏 3 技能最后一拉指向自身格子中心。
  - 方向性：大部分为**径向**（指向拉力起点）；拐角冰面等机制强制修正为**方向**。
  - 力的大小：实际受力 = 列表值（与推力不同，无 ×0.01）。
  - **拉力表**（受力等级 / 列表值 / 受力 N / 拖拽时间 s / 初速度 / 理想移动距离 d=2 / d=3；d = 敌人在干员身前的格数）：

    | 受力等级 | 列表值 | 受力(N) | 拖拽时间(s) | 初速度 | d=2 | d=3 |
    |---|---|---|---|---|---|---|
    | ≤−3 | 0 | 0 | 0.5 | 0 | 0 | 0 |
    | −2 | 2 | 2 | 0.5 | 0 | 0.0320 | 0.0325 |
    | −1 | 10 | 10 | 1 | 0 | 0.5699 | 0.9240 |
    | 0 | 40 | 40 | 1 | 0 | 拉至干员身上 | 拉至干员身上 |
    | 1 | 42 | 42 | 1 | 0 | 拉至干员身上 | 拉至干员身上 |
    | 2 | 44 | 44 | 1 | 0 | 拉至干员身上 | 拉至干员身上 |
    | ≥3 | 46 | 46 | 1 | 0 | 拉至干员身上 | 拉至干员身上 |

  - 拉力大小随运动变化：开始运动后 t 时刻拉力 **F_t = F_0·(x_t/x_0)⁴**（x_0 = 拖拽弹道命中时目标与拉力起点距离，x_t = t 时刻距离）。表格距离仅为参考，精确解需按实际情况高精度计算。
  - 弹道命中时确定受力等级及后续拖拽物理参数 → 拉动过程中力度与重量变化**不影响**本次位移结果。
  - **急停**：若**有且仅有单个拉力来源**，拉力作用时间内目标进入拖拽者中心半径 **0.6708** 的圆形区域 → 失衡移速归零（仍保持失衡至作用时间结束；锏 3 技能除外，立即结束拉力）。歌蕾蒂娅 3 技能前 6 段拉力急停半径 0.05；自然结束（非撤退干员）时敌人清空失衡移速并退出失衡。
  - 拉力在力的意义上绑定：每帧生效一次的持续变化力；角色撤退或弹道消失 → 力失去绑定，目标以当前速度依摩擦力规则自由滑动至退出失衡。抛射物默认**5s** 持续时间；命中无法拖动单位时不判定「已拉到目标」，需等 5s 结束才能结束拉动（急停机制同样与抛射物绑定：抛射物提前消失则敌人冲过干员）。
- **捕网**（雪雉类特殊拉动）：类似拉力，绑定干员与弹道；「拉至身前」行为同拖拽，「聚怪」时间可单独设置，聚怪部分指向捕网中心（一般锁定某敌人坐标）；力的大小同拖拽。

### 7.5 异常效果（AbnormalFlag）
- 本质：**开关型二进制数据**，通过 Buff 和状态机控制开关与持续时间；**不是 Buff，不存在持续时间或叠加**；「获得数秒某异常效果」= 获得携带该异常效果的 Buff。部分异常隶属于「无法选择」效果。
- 完整异常效果表（ID / 内部ID / 站内称呼 / 效果）：

| ID | 内部ID | 称呼 | 效果 |
|---|---|---|---|
| 0 | STUNNED | 晕眩 | 状态机切换至 STUN（无法攻击、释放技能、阻挡敌人类单位；敌人类单位无法移动） |
| 1 | SP_RECOVER_STOPPED | 阻回 | 停止技力自然回复，阻止任何形式的非强制性技力增加；技能期间通常持有；因技能所需技力变化连带导致的技力变化不受阻回影响 |
| 2 | TARGET_FREE | 不可选中 | 无法被不同阵营选中（无法选择类） |
| 3 | BLOCK_FREE | 不可阻挡 | 无法阻挡/被阻挡，自动解除阻挡 |
| 4 | HIDDEN | 隐藏 | 无法触发任何单位未绑定选择器的能力 |
| 5 | INVINCIBLE | 无敌 | 无法被不同阵营选中（无法选择类）；受到的伤害与元素值变为 0；无法触发任何单位未绑定选择器的能力（可影响沉睡单位的伤害在特定情况下可无视无敌免伤） |

- **异常组合（AbnormalCombo）**：持有即视为同时拥有所含异常效果，但**不受针对单一异常效果的免疫/无视影响**。
  - ID 0 SLEEPING 沉睡 = 无法行动 + 无敌 + 不可阻挡。
  - ID 1 SHELTERING 闭锁 = 强制缴械 + 无敌 + 不可阻挡。
- **异常免疫 / 异常组合免疫**：对应异常效果无法生效、**无法被检测**（不清除携带该异常的 Buff，免疫结束时重新起效）。便捷抗性（布尔配置，开启=TRUE 时初始化获得）：
  - `stunImmune` 晕眩抗性 / `silenceImmune` 沉默抗性 / `sleepImmune` 沉睡抗性 / `frozenImmune` 冻结抗性 / `levitateImmune` 浮空抗性 / `disarmedCombatImmune` 战栗抗性 / `fearedImmune` 恐惧抗性 / `palsyImmune` 麻痹抗性 / `attractImmune` 诱导抗性 / `teleportImmune` 传送抗性 / `groundBoundImmune` 缚地抗性。
  - 反隐（隐匿免疫）：使迷彩失效，但**无法阻止其他机制对迷彩的检测**（同时持隐匿免疫与迷彩的单位会被部分非索敌能力认为「有正常生效的迷彩」）；部分单位受隐匿免疫影响瞬间有特殊交互（土遁忍者）。
  - 浮空免疫：禁止一切含浮空异常的 Buff 施加（施加逻辑可能相应失效）；缚地免疫同理。
  - 传送免疫：`被传送`异常本身无效果，仅有其免疫有实际用途（传送免疫实现方式之一）。
- **异常反制（AbnormalAnti）**：获得含反制效果的 Buff 时，包含对应异常的 Buff 被**立刻清除**；反制生效期间无法添加。区别于免疫：反制清除并阻止添加，免疫只令异常暂时无法生效。
- **异常效果标记（AbnormalFlagMask）**：位标志枚举合并所有异常效果，每位 = `1 << abnormalFlag的ID`。例：晕眩 + 不可选中 = `1<<0 | 1<<2` = 5。
- 统一检查分类：
  - **无法选择**（`get_targetFree`，检查 5 个）：隐匿、不可选中、无敌、塔不可选中、对地规避（索敌者行动方式不为地面时忽略）。持有任一 → 常见异阵营「选择」行为无视该单位。部署保护期间或 DISAPPEAR 状态机下自动视为无法选择。直接选中的能力不受影响。
  - **可选性**（`enableAdvancedOptions` 检测）：无法选择类 + 禁疗 + 孤立（**不含迷彩**）。
  - **阻止攻击**（`get_canUseAtkOrCbt`，检查 8 个）：晕眩、无法行动、浮空、冻结、麻痹震颤、缴械（无敌时忽略）、强制缴械、小睡。**失衡不是异常效果**（状态机），不阻止攻击；战栗不影响此检查（如用水遁忍者伤害的检查在失衡或战栗下仍能造成伤害）。
  - **阻止能力**（`get_canUseAbility`，检查 6 个）：晕眩、无法行动、浮空、冻结、麻痹震颤、小睡（许多能力可绕过）。
  - **阻止移动**（`get_canMove`，检查 4 个）：束缚、自缚、冻结、浮空（晕眩/无法行动/麻痹震颤因状态机无法移动但不属于此类）。
  - **对友方隐藏**（`get_isHiddenToAlly`，未绑定选择器时，检查 3 个）：隐藏、小睡、无敌。
  - **对非友方隐藏**（`get_isHidden`，未绑定选择器时，检查 2 个）：隐藏、无敌。
- **可影响沉睡单位的伤害**：8 号 SharedFlag（`DAMAGE_CAN_HURT_SLEEPING_ENTITY`）。判定：处理无敌的「无法受到伤害与元素损伤」时，先假定目标具有沉睡免疫，若仍具有无敌/隐匿/不可选中/塔不可选中之一 → 即使无视沉睡伤害也归零；否则可因该 SharedFlag 无视无敌。目标处于出场/部署/消失状态机自动通过该判定；**小睡不是沉睡**，无视沉睡的伤害无法影响小睡单位。

### 7.6 特殊机制
- **单位类型**：角色类（CHARACTER：以格为单位部署/放置、始终处于格子中心、不可被推/拉、可阻挡敌人、默认受击判定区域半径 0.25 圆、默认阵营我方）；敌人类（ENEMY：可寻路自发移动产生小数坐标、可被推/拉、可被角色类阻挡、默认受击判定区域半径 0.1 圆、默认阵营敌方；阵营我方/中立时不可被角色类阻挡）。
- **阵营**：我方/敌方/中立。默认**敌方单位尝试选择我方单位时也会尝试选择中立单位**。敌人类单位均无职业。
- **无职业**：总是能被限定职业的索敌选中（「最终结果不包括无职业」的限定职业索敌除外）。
- 额外定义：
  - 无害目标：到达路径终点不扣关卡生命值、不触发警报（由关卡/召唤行为配置）。
  - 非首要目标：在场不阻止战斗结束（伴随「不计入待处理目标数量」时为敌人自身配置，否则为召唤行为配置）。
  - 特殊生命值机制：成功受到伤害并应用生命值变化时**生命值只降低 1 点**（不论伤害多少）；部分仅接受部分类型伤害（不符类型不降生命值）；不影响伤害本身（基于伤害的治疗/损伤按「确实造成 X 点伤害」处理）；图鉴描述「需要 X 次伤害击倒」，生命值即所需伤害次数。
- 额外术语：
  - 可空降：特殊入场动画，非战斗开始即生成的场合路径起点可不固定为侵入点（图鉴「能够从战场中出现」）。
  - 攻击阻挡的所有敌人：不是真的检测阻挡对象，而是将每次攻击最大目标数保持与**当前阻挡数**一致（至少保留 1）；目标数于攻击开始时决定，途中阻挡数变化不影响当次。
  - 切换模式：退出当前 UnitMode 进入另一指定模式；切换至当前模式失败且不触发相关效果；切换时中断正在进行的普通攻击并清空当次攻击间隔（相当于可立即再攻击一次）。
  - 重生：受到足以致命的伤害时生命值不降低而进入重生状态；重生强制中止当前行动，一段时间内/后生命值回复至一定比例；期间处于重生状态机（无敌 + 无法阻挡）；清空自身白名单外 Buff；重生结束重置通用技能与当前形态技能冷却为初始冷却；部分强制击杀可跳过重生。
  - 闪现：带动画的传送；前摇动画后传送至目的地；部分闪现进入闪现状态机提供无敌 + 不可阻挡 + 失衡免疫（「提供闪现保护」= 整个闪现动画期间处于闪现状态机）。
  - 闪现前进：先确定闪现方向（有下个检查点用指向下一路径点的直线方向，否则当前移动方向）；目的地 = 当前位置沿闪现方向移动「闪现距离」；目的地为自身可通行地块（格子判定）才传送（图鉴「可以快速移动至其身后」）。
  - 流失（生命流失）：带「跳过各种伤害处理事件」标记的伤害；不触发来源的计算伤害时/输出伤害时/成功造成伤害时，以及目标被计算伤害时/受到伤害时/应用伤害时/成功受到伤害时；通常为真实伤害（物理/法术流失会受对应抗性衰减）；治疗也有（生命复原）。
  - 明晦属性：对同属性单位伤害，计算伤害时攻击力倍率**降至 60%**；对异属性**提高至 140%**（默认值，可随敌人配置/晦明之印地形变动；以双方皆有明晦属性为前提）。
  - 载客：自身不处于消失/失衡状态、不持有晕眩/冻结/浮空/睡眠时可载客；已载客未满且符合条件单位处于载客半径内 → 装载为乘客（立刻进入消失状态）；退场时卸载（传送至卸客区域随机位置、取消消失状态、可能更改路径、停驻则跳过）。
  - 「叠叠乐」：特殊载客逻辑；组合模式出场；载客后退出组合模式/退场时在自身位置卸客并将乘客剩余路径替换为自身剩余路径；出场即组合模式则以自身路径召唤 1 名乘客。
  - 吞噬：强制击倒目标；若为干员则锁定在待部署区并使其再部署时间归零；自身死亡解除锁定（卡片顶部红黑色吞噬标志）。
  - 锁定在待部署区中：无法被拖动至战场；**封印在待部署区中**：无法被点选。
  - 附着：通常召唤在地块中心，对附着范围内满足条件的单位施加附着效果；随附着类单位退场解除；附着对象退场时附着立即结束（可能导致附着类单位死亡）。
  - 鉴定：第一阶段每 0.1s 若自身被阻挡/处于我方单位视野范围内（含装置类我方单位视野）→ +2 鉴定进度，否则 −1；进度 ≥300 进入第二阶段；第二阶段敌对时标红，每 0.1s 被阻挡/视野内 +3 否则 −1（不回落至第一阶段），≥300 完成。
  - 能量：每 1 点能量 → 攻击力 +10%、防御力 +20%。
  - 暴露：暴露状态的我方单位获得 20% 脆弱，可无视封阻物/作战专用掩体触发敌人的直击。
  - 直击：技能仅自身未被阻挡且所在行列（基于射线、碰撞判定）存在未被遮挡或暴露的我方单位时触发；弹道碰撞半径 0.3（无视迷彩），优先命中【临时掩护】生效时的临时掩护装置。
  - 非移动：①敌人类单位不处于出生/重生/失衡/闪现状态且未进行自主移动 → 视为非移动单位（即使发生实际位置变化如阻挡偏移、被传送）；②职业为装置的角色类单位也视为非移动。
  - 交战：矿工游击队进入自身 0.9 半径时双方获得束缚（不影响攻击索敌）；可同时交战数量有上限（不选已在交战中的，优先最近）；除非一方退场/离开半径 1.0 否则不结束。
  - 搜捕：选择并追踪搜捕范围内 1 名触发警戒的我方单位（低地目标优先 > 距离最近，不可对空）；攻击范围内存在满足自缚条件目标时自身获得自缚；追踪期间不改变目标；无目标时结束回到初始模式。
  - 御龙：常态持有不死；300 御龙进度槽（可被翔虫技累加）；受致命伤害或进度蓄满 → 昏迷形态（仅一次），昏迷 30 秒未蓄满被强制击倒；蓄满视为已处理并待命（给予御龙装置）；昏迷/御龙形态持有无敌 + 孤立 + 不可阻挡 + 自缚 + 晕眩/冻结/恐惧/诱导/沉睡免疫。
- 战场效果：
  - **洋红蒸汽**：生成时对范围内我方单位造成 **250 点无来源法术伤害 + 350 点灼燃损伤**；范围内地面敌方受到的物理/法术伤害 **降低 75%**，我方受到的物理/法术/真实伤害**提升至 150%**；无法与纯白水汽共存（已存在时 1 帧后覆盖）；无法生成于景观喷泉四周/红门/蓝门/地穴（默认数值，关卡可变）。
  - **纯白水汽**：生成时对范围内地面敌方造成 0 点无来源法术伤害，待部署区水汽汽水瓶剩余再部署时间 −1s；范围内地面敌方受到的物理/法术/真实伤害提升至 150%，我方受到的物理/法术伤害降低 75%；互斥规则同洋红蒸汽。
  - **田地/病害值**（范围 0～100；未隔断连片田地共享最大病害值）：未被污染（=0）时其中我方单位**每秒回复 50 点生命值**；受污染（>0）时每 0.2s 释放 1 点病害值累加至最大病害值，每 1 秒更新实际病害值直到达到最大病害值（与最大值的差值每 25 点 +1 实际病害值，小数上入）；受影响我方单位立刻受到 基础伤害 + 实际病害值×一定比例 的环境法术伤害，且每秒再受一次；无法影响高地地块上的我方单位（数值关卡可变）。
  - 稳固锁链：干员在接驳地块部署需向支援范围内最后部署的、锁链数未满的干员发射锁链（无法连接则无法部署）；每名干员最多维持 2 条；失去锁链维持进入「颠簸」（10s 晕眩，10s 后强制退场；期间接受锁链可脱离）；支援范围 = 5×5 缺角菱形（上下两行各 3 格、中间行 5 格）；锁链以双方中心点为端点、宽度 0.5，敌人碰撞获得 3s 停顿（离开锁链碰撞范围后才能再次获得），部分敌人激活受影响能力。
  - 盲区：反向迷彩的索敌影响机制（详见 7.3；装置本格不算盲区；没有视野的单位也可能有盲区）。
  - 兔子洞：入口地块令进入的敌方单位（无视目标可选性、不可对空）**0.1 秒后进入消失状态**；3 秒后传送至随机未被占据的出口并将路径替换为出口预设路径；出口选择权重随机（概率 = 本出口权重 ÷ 所有未被占据出口权重和；权重 0 的出口仅在所有其他出口都被占据时才尝试）；出口被角色类单位占据则不可作传送目标；3 秒后无出口可用 → **强制击杀**。
- 引擎机制：
  - 静态刚体（Kinematic/Static）：可进入失衡并启用物理，但物理层面无法产生速度或移动；失去施力后立刻退出失衡（失衡有 **0.1 秒保底持续时间**）；与失衡免疫不同（后者无法进入失衡）。
  - 失衡移动阻尼（LinearDrag）：通常敌人类刚体为 0（无阻尼）；不为 0 时失衡移动受正比于当前速度的阻力（推动/拉动时速度与位移量降低）。
- 复用机制：
  - 被阻挡时使用相同攻击 / 不同攻击：阻挡攻击与普通攻击共用冷却（相同）/ 独立冷却（不同）；「相同」时未被阻挡触发的普通攻击在被阻挡后**可被战栗打断**，「不同」时不可。
  - 空攻击：可被阻挡但不进行普通攻击的敌人被阻挡时尝试空攻击；**不属于攻击，不触发任何攻击相关效果**；解除阻挡后短暂时间内可能无法移动。
  - 直接选中：仅筛选提到的条件，无视未提到的条件（默认须满足：可选中行动方式为地面的单位、实体类型为默认类、同阵营受孤立/异阵营受无法选择/对立阵营受迷彩干扰、治疗受禁疗干扰）。
  - 动态持续时间：未标注持续时间的技能（强力击类）触发后使用等同**实际攻击间隔**的持续时间进入技能状态机；动画无法拉伸/缩短至一致时可能延迟结束或提前结束。
  - 死亡爆炸：默认可沉默；死亡（含坠落）时不处于沉默 → 于攻击弹道发出点（无则原地）释放延时爆炸弹道，延迟结束后对半径内我方单位造成伤害；爆炸延迟 ≥ 死亡动画时间时伤害失去来源（「来源无效」）。
  - 强制部署：无视地块常规部署条件（不可部署、近战位限定等）与单位部署条件强制部署；被部署单位部署类型属性临时重写为「全部位」；与部分「无法部署」特殊机制互相无法无视（反之亦然）。
  - 部署保护：部署状态机期间（直至「部署完成 Located」）无法被敌对阵营选中（类似不可选中）；通常持续至部署动画播放完毕那一帧。
  - 部署保护失效：部署状态机下切换模式导致状态机被提前切出/重启 → 被误判为部署完成，部署保护失效（表现类似无部署动画的召唤物）。
  - 生命复原：即治疗（伤害类型）的生命流失；不受禁疗制约、不触发治疗相关事件（治疗量增减/额外效果）、无溢出治疗量；不触发输出治疗时/受到治疗时/应用治疗时/成功受到治疗后/产生溢出治疗量时。
  - 移动创伤（Rupture）：每个可移动单位自出现后每 5 帧记录位置并与上次位置计算直线距离，计入总移动距离（格）；移动创伤 Buff 开始时记录当前总移动距离，之后每 0.066 秒更新一次（结束时额外更新一次），每次更新对持有者造成 (当前数值−上次更新数值)×每格伤害比例 的**预计算真实持续伤害**；两次更新间数值差 >4 格则不造成伤害（数值差为 0 也会产生一次伤害，但因攻击力为 0 被取消）。
  - 拆分伤害：一段伤害计算后均分为数段（每份完全复制伤害数据，但不触发受击回复、不再计算防御/法抗/元素抗性）。
  - 停顿免疫：常驻一个无效果的 Buff，与停顿不同名但可叠加并覆盖停顿（优先级更高）→ 停顿无法生效；因不同名无法被画地为牢、毋畏恐惧响应。
  - 免疫传送：常驻无效果 Buff；存在「免疫传送(黍)」「免疫传送(余)」两种，默认指(黍)。
  - 吞噬免疫：`DEVOUR_IMMU` 标签；部分吞噬效果不会强制击倒/不会以该单位为目标。
  - 不可重伤：常驻无效果 Buff 使自身无法被施加重伤；自身持有重伤时无法获得不可重伤。
  - 加强版浮空：同时含浮空 + 浮空强化异常的 Buff；施加时不因已浮空而取消。
  - 已损失生命值判定：若 `初始比例 − 阶段比例×当前阶段数 − 当前生命值比例 > 阶段比例` 且 `当前生命值比例 > 0%` → 通过判定，当前阶段数改为 ⌊(初始比例 − 当前生命值比例) ÷ 阶段比例 + 1⌋（向下取整；阶段数初始为 1；初始比例默认 100%；可配置保底比例：当前比例低于保底时代替之）。
  - 强制触发技能：中止当前攻击/技能，**无视技能冷却/技力和沉默/缴械**，清除麻痹震颤，触发指定技能；状态机不在 Attack/Combat 则切换至 Attack（直接打断失衡状态机，但无法打断晕眩/冻结/浮空状态机）；需要技力则照常扣除。变体：
    - 强制触发技能(受制约)：受冷却/技力/沉默/缴械制约。
    - 强制触发技能(不打断)：不中止当前攻击/技能（处于攻击/技能时无法触发）。
    - 尝试触发技能：不中止且受制约。
  - 释放当前波次：释放当前波次所有敌人不再阻止下一波（`trackSourceAtNextWave`=true 时触发者移动至下一波次）。
  - 免死：①在生命值归 0 前阻止当次生命归 0；②成功阻止后对触发 Buff 执行其他效果；多个免死按 ① 的优先级依次触发、单次最多触发一个；持有不死时通常不触发。
  - 弹药倾泻：主动关闭技能本质是第二次触发技能；发生弹药倾泻时**不会关闭技能**而是记录剩余弹药并消耗等量发动一轮特殊攻击（期间无法主动关闭）；攻击完毕/被中断后若还有弹药技能回到正常状态；弹药耗尽结束不算主动关闭。
  - 覆写：单位数值范围的上限或/和下限不再遵循默认数值范围。
  - 自动路径：召唤时以召唤者位置（或配置起点）为起点、直线距离最近的目标保护点为终点生成路径（不考虑可抵达）；地面行动方式下路径距离超过「路径安全阈值」（最短路径含障碍物/地穴）→ 召唤失败；召唤位置为自身所在不可通行地块也失败。
  - 转向速度：弹道速度（向量）的变化权重；下帧方向 = 原方向×(1−转向速度) + 目标方向×转向速度（详见 7.9）。
  - 借用持有者的攻击力：`攻击力 = 自身攻击力 × 文本倍率`；`攻击力倍率 = 持有者攻击力 ÷ 自身攻击力`；伤害来源仍为召唤物（用召唤物自身穿透属性）；自身攻击力为 0 时无法产生伤害（倍率强制锁定 100%）；找不到持有者时倍率视为 100%。
  - 扩张正弦方向：每次进入该移动方式时以当前位置为原点、当前移动方向为 x 轴正方向做 sin(x) 或 −sin(x)（随机 50%），第 n 周期振幅 = 基础振幅×n（1≤n≤3）；沿函数轨迹以固定 x 方向速度移动。
  - 泄压准备（危机合约词条）：每次手动部署并消耗部署费用（即使 0）时，若满足 ①非「免费部署」机制 ②上次退场原因（若有）不为「移动」 ③当前费用 > 部署所需费用 → 额外扣除机制标注费用（不足则扣至 0）。
  - 传送带矢量：临时性数据（多个矢量矢量加法）；在单位自主移动处理完毕后再处理（先自主移动再被传送）；尝试传送至 当前位置+矢量，目的地为非坑洞类不可通行地块时拆分为竖直+水平两次传送（竖直不合法 → 取消并直接终止；水平不合法 → 取消本次）；水平传送时若水平矢量模长非 0，额外检查 当前位置+[±0.2,0]（取决于方向），不合法则水平部分至多传送至距该不合法地块中心垂线 0.7 格处（左右保留 0.2 格空间）；对持有传送抗性（被传送免疫）的单位不生效；判定仅依据地块可通行与否，可产生「非预期」位置（如地面单位被传送至玉门天灾工事）。
- 特殊计算方式：曼哈顿距离 = ∣行差∣ + ∣列差∣（地块位置计算，必为整数）；切比雪夫距离 = max(∣行差∣, ∣列差∣)（必为整数）；「无限远」= 当前地图长与宽的更高者，或表示距离不重要/无限重复判定至地图边缘。

### 7.8 仇恨（攻击目标选择优先级精确规则）
- 页面警告：**2.7.01 版本起角色类单位的仇恨计算、进阶选择器、排序逻辑出现较大变动，本页仅供参考**。
- **仇恨值公式**（按实体类型选用）：
  - 敌人类：`仇恨值 = 10⁸ × 嘲讽等级 − clamp(路径距离, −10⁸, 10⁸)`。
    - 所在地块可到达目标路径点：路径距离 = 终点距离（以所在地块坐标为起点，直接串联所有路径点到终点的**曼哈顿寻路距离之和**，「传送门」之间距离除外）+ 修正值（「自身所在具体坐标 → 当前地块中心」向量 V 在前进方向上的投影，可负）；单位为格。
    - 不可到达或在地图外：路径距离 = 当前坐标至当前目标路径点的直线距离。
    - 直观理解：「自身离终点/路径点越近，仇恨值越高」。
    - 2026-08-01（2.7.61）起：敌方公式中嘲讽仇恨翻 **10000 倍**（已计入公式），并为路径距离添加与 1 级嘲讽相当的上下限 → 持嘲讽敌人的仇恨大于路径上有坑洞的单位。
  - 角色类：`仇恨值 = 3×10¹¹ × 嘲讽等级 + clamp(创建时间, 0, 10000) × 1000 + 同帧内已部署单位数 × 1`。
    - 创建时间见下；同帧内已部署单位数每帧更新（区分暂停部署时单位的仇恨值）。
    - 2.7.01 起整体放大 1000 倍（已计入）并引入同帧内已部署单位数，不再出现角色类同仇恨值；2.7.61 起干员嘲讽等级独立翻 30000 倍（已计入），+1 嘲讽即数值溢出、仇恨机制几乎无法正常处理。
    - 直观理解：「时间、顺序上越晚部署/出现，仇恨值越高」。
  - 仇恨值类型为**定点数**（敌人类计算途中为浮点数，计算完成后转译）。
- **创建时间**：单位创建时（干员部署、敌人出现）从「战斗开始」算起的当前战斗计时，上下限 **[0, 10000]** 秒，一经取值不再变化（战斗计时每游戏帧更新一次 ≈ +0.033s）。部分仇恨过滤器不使用仇恨值而直接用创建时间计算参考值。
- **仇恨过滤器（postFilter，共 79 个，其中 10 个占位）**：
  - 流程：框定所有可选目标（默认实体创建顺序）→ 一次过滤器排序/筛选/打乱；可能对仇恨值二次计算。
  - 参考值（权重）：32bit 浮点，**越低越靠前**（越容易被选为目标）。自凯尔希起引入**双权排序**：两个参考值，先看第一参考值，相同才看第二参考值（不易出现数值「跃迁」）。
  - 排序：稳定性排序（类似插入排序）；同值项保持实体创建顺序 → 更早创建（通常部署）的单位优先。
  - 比对精度默认 **0.001**；4 号（仇恨降序）与 76 号（与自身间寻路距离升序）为 **0.1**。原理：参考值 × 精度倒数后转整型比较（辞岁行后角色类嘲讽 1 级 = 10⁷，×1000 后极易触及整型 ±21 亿上限导致计算错误）。
- **全部过滤器**（ID｜名称｜规则；「双权」= 第一参考值优先、相同看第二；未注明时第二参考值多为仇恨值相反数）：
  - 0 ALL：不排序，用默认列表顺序（群体/无差别攻击）。
  - 1 DIST_TO_EXIT_ASC：终点距离升序（敌人类专有，非敌人类参考值恒 0；暂未使用）。
  - 2 HP_RATIO_ASC：生命比例升序（苦艾 1、始海穿刺者、富营养的穿刺者）。
  - 3 HP_RATIO_NOT_FULL_ASC：生命比例升序（排除满生命值）（医疗普通治疗/治疗技能）。
  - 4 HATRED_DES：**仇恨降序**（参考值 = 仇恨值相反数）（一般攻击/技能索敌、部分群体攻击）。
  - 5 HP_RATIO_NOT_FULL：仅生命值未满目标，不排序（参考值全 0）。
  - 6 HATRED_DES_FLY_FIRST：优先飞行单位，仇恨降序（双权：飞行=0 否则 1；次：−仇恨）（安德切尔；一般速射手不用）。
  - 7 HATRED_DES_RANGED_FIRST：优先远程单位（图鉴攻击方式含「远程」=0），仇恨降序。

### 7.9 弹道（抛射物）
- 弹道携带完成一次攻击所需信息（远程攻击的核心）；粗略判断：伤害和特效非即时即为弹道（能天使普攻的「子弹」仅为特效，无弹道）。
- **移动行为**（内部 ID｜称呼｜移动方式｜移动类型）：

| 内部ID | 称呼 | 移动方式 | 移动类型 |
|---|---|---|---|
| 无 | 静止 | 不移动 | 不可变 |
| AdvancedMovement | 直线 | 以当前位置直线向目标移动 | 可变 |
| ParacurveMovement | 抛物线 | 抛物运动（如炮手炮弹） | 可变 |
| RotateAroundMovement | 环绕 | 按角速度与半径绕目标旋转 | 可变 |
| FarthestPointMovement | 向前飞行 | 无限向一个方向飞行，碰撞到的可选对象视为目标 | 可变 |
| NetCatcherMovement | 捕网 | 见雪雉捕网 | 可变 |
| AttachToTarget | 附着 | 不移动，可配置跟随目标移动 | 不可变 |
| HarpoonMovement | 套索弹道 | 直线向目标移动后跟随目标移动（发点与目标间画线） | 不可变 |
| AmiyaDefaultMovement / AmiyaS2Movement | 阿米娅普攻/二技能（定时命中） | 命中时间固定，飞行速度由距离与时间计算 | 不可变 |
| GroupedMovement | 组合 | 需包含的 Movement 全部可变才为可变 | 特殊 |

- 视觉效果通常与实际移动方式无关。
- **转向速度**：格式 A/B（B 总权重、A 目标方向权重）；下帧方向 `d' = d·(B−A)/B + t·A/B`（d 本帧速度方向、t 目标方向）。例：d=(1,0)、t=(0.7071,0.7071)、A/B=1/5 → d'=(0.94142,0.14142)，下帧速度 (9.4142,1.4142)。
- **最大存在时间**：有目标弹道从出现起的最大存在时长，达到后自动消失；**大部分弹道存在时间归零时若仍未击中目标则立刻视为击中**（可配置）；常见 3/5/10 秒；技能与弹道绑定时，弹道无法消失则技能持续到弹道消失；受变速效果影响时最大存在时间同比例变化（存疑）。
- **可变速模式**（逻各斯 3「延异视阈」减速）：`AUTOMATIC`（含可见视觉特效则可减速）、`YES`（可减速）、`NO`（不可减速）；移动类型为**不可变**时始终不可变速。
- **可消除模式**（视阈清除）：`AUTOMATIC`（与可变速结果一致）、`YES`/`NO`；非自动识别下可变速与可消除独立（可能存在可减速但不可消除、或可消除但不可减速的弹道）。

### 7.10 常见同名状态（Buff 同名不叠加）
- 注：该页面原 wikitext 整体处于注释（编辑中）状态，以下为注释内容转录。默认叠加方式：新 Buff 以「无效果且无法被检测」的状态存在于 Buff 列表中，当所有比它更早或优先级更高的 Buff 结束时才正常生效；「免疫」处理方式 = 持有一个更高优先级但无效果且无法被检测的同名 Buff。
- 鼓舞类：鼓舞（特定属性获得的最终加算增益，数值 = 鼓舞来源者对应属性的最终乘算倍率；每个属性分别计算）；生命鼓舞/进攻鼓舞/守护鼓舞（同效果取倍率最高）。
- 增益类：技力光环（SP 自然恢复速度提高，取最高）；庇护（受到物理与法术伤害降低一定百分比，取最高）；抵抗（可抵抗状态下状态持续时间减少速度提升）；散射手特性（攻击力倍率提升）；净化（瞬间清除所有可抵抗状态）。
- 削弱类：能力失效（含沉默异常）；脆弱（受到伤害提高，取最高）；法术脆弱（法术伤害提高，取最高）；重伤（移速下降且无法被阻挡，一定时间后自然倒下，被击败使击败者技力增加；含禁用近战异常）；禁锢（攻速 −50）；缴械（含缴械异常）；沉睡（含沉睡组合）；缴械且不能使用技能（缴械 + 沉默）；技力消逝（每 1 秒减少 1 点技力）；重力损失（重量 −1 级，直接加算，即失重）。
- 控制类：停顿（移速 −80%）；束缚（含束缚异常）；沉睡（无法行动 + 无敌）；晕眩（无法攻击治疗、无法释放技能；我方无法阻挡、敌方无法移动；含晕眩异常；**可抵抗**）；寒冷（攻速 −30；敌人→干员：已有寒冷或冻结时本 Buff 变冻结；干员→敌人：已有其他寒冷时增加一层冻结；**可抵抗**）；冻结（敌人→干员：无法攻击治疗释放技能；干员→敌人：额外防御力 ±0、法抗 −15；**不可抵抗**）。
- 伤害类：烈焚灼息（每秒固定值真实持续伤害，**初始 50/s，30s 内线性提升至 230/s**；可抵抗；延长时间）；神经毁损/侵蚀毁损/灼燃毁损/凋亡损伤爆发（见元素页）。
- 战斗机制类：明属性/晦属性（对同属性单位攻击时攻击力降至 60%、对异属性提高至 140%）；游泳（优先级 1，覆盖 BUFF `under_sea`）。
- 符文：源石刺激（持续损失生命值，但攻击力和攻速大幅度提升）。

### 7.11 伤害分类
- **伤害类型（damageType，5 种）**：
  - 物理：基础物理伤害 = 使用属性 − 目标防御力（「使用属性」大多为自身攻击力，也存在其他属性/固定值）。
  - 法术：基础法术伤害 = 使用属性 × (100 − 目标法术抗性)/100。
  - 真实：基础真实伤害 = 使用属性，不计算任何防御属性；**不指定伤害类型的伤判效果可以对真实伤害生效**（可被减免、格挡或闪避）。
  - 治疗：基础治疗量 = 使用属性；无特殊逻辑的治疗默认选择生命值不满单位；默认受禁疗制约。
  - 元素（2023-07-06 加入）：基础元素伤害 = 使用属性 × (100 − 目标元素抗性)/100；另有「损伤抵抗」属性减免元素损伤值。
- **攻击类型（attackType，5 种）**：无类型（NONE）、普通（NORMAL，站内省略时默认为此类型，但对伤害筛选省略 = 不判断攻击类型）、溅射（SPLASH，群攻也可能只造成普通伤害）、持续（BUFF，视觉上不依赖攻击的 DOT：「每秒造成……」「移动 1 格造成……」；已知包括自残/地形/装置/机制/集成战略/元素爆发/干员天赋特性/技能等大量来源）、附加（ADDITION）。
- **施加途径（applyWay，4 种）**：无途径（NONE，部分 Buff 造成；对近战/远程途径的效果皆可生效）、近战途径（MELEE，不产生弹道的攻击；「阻挡攻击/非阻挡攻击」与近战/远程途径无明确对应关系；与图鉴「攻击方式」标签无关）、远程途径（RANGED，产生弹道的攻击）、全途径（ALL，极少 Buff）。
- **标签类型（sharedFlag，11+ 种）**：
  - 非致命伤害（`DAMAGE_IS_UNDEADABLE_THIS_TIME`）：应用时至多将目标生命值降至 1 点（重伤机制常用）。
  - 环境伤害（`IS_ENVIRONMENT_DAMAGE`）。
  - 生命流失（`SKIP_MODIFIER_EVENT`）：跳过伤害计算以外的所有步骤与事件（非真实伤害的流失标注为「物理流失/法术流失」）。
  - 可影响沉睡单位的伤害（`DAMAGE_CAN_HURT_SLEEPING_ENTITY`）。
  - 溢出部分可产生屏障的治疗（`HEAL_CAN_GENERAL_SHIELD`）：记录溢出治疗量并触发响应事件。
  - 强制显示红字的伤害（`FORCE_TO_DISPLAY_CRITICAL_NUMBER`）：始终视为暴击显示红字。
  - 类斩杀伤害（`INSTANT_KILL_LIKE_DAMAGE`）：部分效果不响应（如愧悔魂灵圣杯光环）。
  - 不可变的伤害（`IS_NOT_CHANGEABLE_VALUE_MODIFIER`）：不受大部分变动伤害逻辑影响。
  - 撼地者主目标伤害（`APPLY_TO_HAMMER_SUBCLASS_MAIN_TARGET`）/ 撼地者溅射目标伤害（`APPLY_TO_HAMMER_SUBCLASS_SPLASH_TARGET`）：标记主/溅射目标身份，享受对应攻击力倍率。
  - 等（11+ 种，其余未列）。
- **其他特征**：
  - 预计算伤害：计算逻辑与造成逻辑分离，通常**没有 ON_CALCULATE_DAMAGE 事件**（所有缓存攻击力的伤害均为预计算伤害）。
  - 计算后伤害：没有计算逻辑，连防御/抗性和攻击力倍率增减都无法处理。
  - 普通攻击的伤害 / 技能攻击的伤害：仅攻击本身造成的伤害，不含攻击附加 Buff 的伤害（景观喷泉识别）。
  - 无来源：造成伤害时被特殊定义，无法追溯伤害来源（伤害来源无法被选中 ≠ 无来源；衍生物伤害可追溯主人；击杀来源追溯不依赖伤害来源，无击杀来源时默认为被击杀者自身）。
  - 致命伤害：理论上能令生命值 ≤ 0 的伤害，将触发致命相关时点效果；致命/非致命可「共存」于同一次伤害。
  - 弱点伤害：在 ON_CALCULATE_DAMAGE 事件中处理。
- **攻击附加效果**：攻击本身附加的 Buff **先于**攻击本身的伤害生效（可通过「攻击造成 0% 伤害 + 附加先伤后效 Buff」实现先伤害后效果）；攻击本身附加的元素损伤**晚于**攻击本身的伤害生效（不包括通过攻击附加 Buff 施加的元素损伤）。

### 7.12 技能
- **技力需求类型**：
  - 自动回复：技力随时间自动回复，通常每秒 1 点。
  - 攻击回复：每次攻击回复 1 点；**连击时每次攻击都能获得技力**（近卫-剑豪分支特性例外：二连击仅回复 1 点）。
  - 受击回复：每次被攻击回复 1 点；部分「无法触发受击回复」的伤害不触发。
- 触发后消耗技力，技能持续期间进入**阻回**。技力最小单位为 1 点，**无小数部分**。
- 自动回复实现细节：隐藏「技力冷却槽」每秒完成冷却补充 1 点；**当前剩余冷却时间 < 10⁻⁵ 秒（0.1ms）时视为冷却完成**（+1 SP 并不断 +1s 冷却直到 ≥10⁻⁵）；阻回或技力满时保留剩余冷却时间、计时暂停；「技力自然回复速度」的修改实际是对冷却槽的修改。
- 技力最大储存量 = 技力需求（入场时预先充入「初始技力」）；技力需求与技力消耗不完全等同（充能技能、玛露希尔等）。
- **触发条件**：自动触发（满足条件自动触发；通常无白色边框，例外：白雪 2 技能）、手动触发（需玩家交互；通常有白色边框，例外：杰西卡 1 技能）、被动（直接生效，无需触发/释放；部署时触发的部分技能也写为被动）。
- **特殊属性**：
  - 可充能：「可充能 X 次」= 当前技力上限 = 技力需求 × X；充能达到上限时可能立刻产生额外效果（立刻释放一次/攻击范围变化/攻击动作变化）；技力流失时充能次数实时降低。
  - 蓄力：可充能的变种（实现为可充能 2 次），仅满充能释放触发额外「蓄力效果」（开启标记变橙红）；无论何时发动通常都消耗所有技力。
  - 弹药：开启后不计算持续时间而替换为弹药数；技能效果消耗弹药；**下次普通攻击时弹药 ≤ 0 → 退出技能状态**；消耗不受当前弹药数限制（可出现负数弹药）；大多数图标带子弹角标（熔泉/极光等少数遗漏）。
  - 可关闭（二次触发）：收到二次触发指令时终止当前效果或产生其他效果；干员处于无法触发技能状态时同样无法主动关闭（缇缇 2 例外）；**弹药倾泻** = 二次触发时额外检查条件并以「弹药倾泻」替换主动关闭（详见 7.6）。
  - 过载：技能持续经过一半进入过载状态（持续条变红、触发额外过载效果；持续条只显示一半）；弹药技能的过载触发条件 = 弹药剩余量降至初始弹药量的一半。
  - 装备应变：技能按钮出现 MODIFY 按钮；以装备应变形式触发技能（直接开启 = 特殊技能触发）或在技能期间激活装备应变效果（二次触发）；使用装备应变效果通常消耗部署费用。
- **敌人技能与 spdata**：敌人技能大多按**冷却时间（Cooldown/CD）**触发；所有冷却技能同时各自进行 CD 和释放判定，有「初始 CD」调整首次释放时间；多个技能完成 CD 时按预设优先级调整释放时间，相同优先级**随机**释放。`spdata` 非 null 即具有技力设定（技力上限与回复需求）；敌人类具有多种技能时技力条类似 RPG「蓝条」（如敌方「弹药」本质 = X 点技力，每次弹药攻击消耗 1 技力释放技能）；敌人技力条也可能用于其他用途（反巫术变位炸弹速度指示器）。**敌人技能攻击大多数情况不属于普通攻击，不受战栗/麻痹影响**（依赖普通攻击的除外）。
- 技能图标归类（主观内容，仅供参考）：背景颜色：红 = 攻击型、黄 = 防护型（生存）、蓝 = 再生型（治疗）、绿 = 战术支援型（部署费用为主）、灰 = 其它型；背景形状：冲击波 = 性能瞬间强化（强力击系）、正六边形 = 单次恢复、上箭头 = 属性增益、尖端扩散 = 爆发、缠绕环 = 模式转换、空心三角形 = 召唤、正方形/空心正方形 = 部署触发、5×5 矩形阵列 = 范围增益、向下断裂箭头 = 削弱、斜十字 = 强力生存；联动干员与部分剧情核心干员（阿米娅/陈/凯尔希/Mon3tr/魔王）的图标存在特殊设计。
