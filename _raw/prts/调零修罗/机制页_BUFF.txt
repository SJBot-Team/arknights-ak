'''Buff'''（有时会被写作全大写的BUFF）是明日方舟中效果付与的最小单位。
* 不仅是常规意义上的正面“Buff”，负面的“DeBuff”、仅供显示特效的效果也属于一种Buff。
实体拥有Buff池（<code>BuffContainer</code>），可以被施加Buff。

Buff的本质是一个数据包，其主要由三部分组成：
* '''属性数据'''，包括修改数值的'''[[数值范围|属性修饰器]]'''与付与特殊调整效果的'''[[异常效果]]'''；
* Buff自身的'''特性数据'''；
* Buff自身动作的'''行为序列'''。
本章主要介绍后两者的作用。
==特性数据==
不仅仅是付与持有者效果，Buff本身也会有一些用于调整的特性。
===持续与触发===
Buff可以有3种类型的持续时间（<code>LifeType</code>）。
*'''<code>IMMEDIATELY</code>'''（瞬间）
: 添加后立刻结束。这种类型的Buff通常用于执行特定的<code>ActionNode</code>。
*'''<code>LIMITED</code>'''（有限）
: 持续一段设定好的时间后结束。
*'''<code>INFINITY</code>'''（无限）
: 除非Buff被手动清除，否则不会自动结束。Buff的无限持续是真正的无限。

除去正常的持续之外，Buff还有一个“扳机触发”（<code>Trigger</code>）的机制。
* 该机制可以使Buff根据设定，在持续时间内，每隔一段固定时间进行一次“触发”。
* “触发”次数可以设置上限。
* Buff可以通过一定的设置，在“触发”这个事件上执行设置的行为序列。
与持续时间类型类似，Buff可以有3种触发类型（<code>triggerLifeType</code>）。
*'''<code>IMMEDIATELY</code>'''（即时/不触发）
:触发计时器被标记为无效。
*'''<code>LIMITED</code>'''（有限触发）
:单个Buff存在期间最大触发次数由变量<code>triggerCnt</code>决定。
*'''<code>INFINITY</code>'''（无限触发）
: 无最大触发次数限制。
: 属于此类型时，若Buff的<code>blackboard</code>中读取到名为“<code>trig_cnt</code>”的值，会自动转为有限触发类型。
===抵抗===
{{Cbox2|lv=1|mdi=true|icon=swap-horizontal|moreclass=mdi-rotate-315|text=关于这部分的内容，您也可以参考'''[[可抵抗状态]]'''。}}
Buff可以有3种{{术语|ba.buffres|抵抗}}模式（<code>statusResistable</code>）。
*'''<code>NO</code>'''（不受影响）
*'''<code>YES</code>'''（受影响）
*'''<code>AUTOMATIC</code>'''（自动判定）
:该设定下程序会自动检测Buff是否包含特定的[[异常效果]]（<code>AbnormalFlag</code>），如果包含则设置为受影响，否则不受影响。
:※目前仅有<code>STUN</code>和<code>FROZEN</code>属于自动检测范围内。
当Buff受抵抗影响时，其计时速度会变为 <code>1 / ONE_MINUS_STATUS_RESISTANCE</code> 倍。

抵抗特性不仅会影响Buff持续的计时速度，同时会影响Buff触发的计时速度。

===生效===
在持续期间内，Buff可以被设置为'''生效'''（<code>enabled</code>）或'''失效'''（<code>disabled</code>）。
* 失效状态下，Buff包含的属性修饰器不生效，触发计时器停止计时，无法响应绝大多数事件，通过Buff名（<code>Buffkey</code>）查找时视为不存在。
* 当一个生效的Buff结束时，其会先被设置为失效，随后标记为结束。
此外，还存在一些响应器用于自动设置生效状态。
* 当Buff的<code>isSilenceable</code>变量设置为<code>true</code>时，代表该Buff具有'''沉默响应'''。
: 该Buff会在持有{{异常效果|沉默}}期间失效。
* 当Buff的<code>isStunnable</code>变量设置为<code>true</code>时，代表该Buff具有'''晕眩响应'''。
: 该Buff会在持有{{异常效果|晕眩}}/{{异常效果|无法行动}}期间失效。
生效状态由Buff的'''叠加策略'''（后述）决定。
===叠加策略===
Buff除存在'''Buff名'''（<code>Buffkey</code>）外，还存在一个'''覆写名'''（<code>overrideKey</code>，通常与Buff名相同）。

当持有者被付与覆写名相同的Buff时，将进行Buff叠加的判定，其由变量<code>disableOverride</code>控制。
* 当开关为<code>true</code>时，代表不会叠加，两者将视为不同的Buff同时存在。
* 当开关为<code>false</code>时，代表可以叠加，此时将由<code>overrideType</code>变量决定叠加策略。
叠加策略共有5种。
* '''<code>DEFAULT</code>'''（默认）<br>叠加时，只有优先级最高的Buff被设置为生效，其它的Buff被设置为失效。
: ※优先级由变量<code>priority</code>决定：其在0及以上时等于该值，为负时则自动计算优先级。<br>※优先级自动计算时：
: 若未设置<code>priorityBBKeys</code>，优先级 = 属性修饰器中所有<code>ADDITION</code>、<code>MULTIPLIER</code>、<code>FINAL_ADDITION</code>值'''之和'''×1000
: 否则，优先级 = <code>blackboard</code>中所有<code>priorityBBKeys</code>的值的绝对值'''之和'''×1000
: ※此策略相当于多个同名Buff存在时仅保留其中最优先的那一个。多见于标注有'''同类效果取最高'''的效果中。
* '''<code>STACK</code>'''（叠加）<br>叠加时，已存在的同覆写名Buff叠加层数（<code>stackCnt</code>）+1，新Buff会被立刻结束。
: 此类Buff可理解为一种“翻倍和可充能”：<br>①若Buff具有属性修饰器，其中的值会按剩余层数动态翻倍。<br>②当Buff的持续时间结束时，改为Buff叠加层数-1并重置持续时间，直至层数为0时结束。<br>变量<code>maxStackCnt</code>将决定最大叠加层数。
: ※此策略用于带有持续时间的可叠加Buff：在持续时间到期而衰减时，衰减1层并重设持续时间至最大。
: ※此策略也可以设定为在持续时间结束时'''耗尽全部层数'''。
* '''<code>UNIQUE</code>'''（唯一）<br>叠加时，新Buff立刻被结束。
: 即仅保留最早一个同覆写名的Buff。
* '''<code>EXTEND</code>'''（刷新）<br>叠加时，已存在的同覆写名Buff剩余持续时间被延长至 MAX(已存在Buff剩余持续时间，新Buff持续时间)，新Buff会被立刻结束。
: ※此策略相当于该Buff'''叠加时，刷新持续时间'''。
: ※如果新Buff的持续时间不大于0，已存在Buff剩余持续时间将被置为0。
* '''<code>EXTEND_TIME</code>'''（加时）<br>叠加时，已存在的同覆写名Buff剩余持续时间被延长至(已存在Buff剩余持续时间+新Buff持续时间)，新Buff会被立刻结束。

==Buff事件与行为序列（ActionArray）==
除了属性修饰器外，Buff还可以在特定的事件上执行其包含的特定的行为序列（<code>ActionArray</code>）。

这些行为序列（<code>ActionArray</code>）和可触发这些行为序列的Buff事件（<code>Buff.Event</code>）记录在<code>BuffTemplate</code>中。

通过Buff触发行为序列前，Buff总是会将自身推入Buff背景（<code>Context</code>）堆栈中，将Buff来源推入<code>source</code>背景堆栈中。

如果同一事件上有多个Buff的行为序列可执行，则按照Buff的添加顺序依次执行。

==其它Buff工具==
* <code>DerivedBuff</code>
: '''衍生Buff'''（或“子Buff”）
: 该Buff在创建时会绑定一个主（父）Buff，主Buff结束时衍生Buff也会自动结束。
: 其它表现与正常Buff完全相同。
* <code>loadFromDB</code>
: 该变量为<code>true</code>时，会优先从<code>Buff_table</code>中加载关于此Buff的预设信息。
