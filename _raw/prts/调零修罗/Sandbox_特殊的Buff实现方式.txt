== 数据库Buff ==
部分Buff记载于数据库中用于快速调用，开启'''使用数据库'''（<code>loadFromDB</code>）参数的Buff即是数据库Buff。部分数据库Buff的数据库内容在站内的[[常见同名状态]]中已有记载。

此类Buff的大部分属性都会直接继承自数据库中的数据，少部分依旧取决于单位自身。即使同为数据库Buff，两个Buff之间也可能存在很大的区别。

== 附属Buff ==
附属Buff是由Buff创建、创建时开启了'''为附属Buff'''（<code>_isDerivedBuff</code>）参数的Buff，创建它的那个Buff便是他的主人Buff。当主人Buff结束时，所有附属Buff都会一并结束。附属Buff存在于各种干员的技能期间施加的Buff里，因为技能本身有一个Buff，给予其他单位的、需要在技能结束时结束的Buff便都可以“挂载”在这个技能Buff下，当技能结束时，挂的所有Buff都会一起结束。

附属Buff的附属Buff不是自己的附属Buff，但主人Buff的主人Buff结束时，会链式反应般全部结束；顺便，一些机制可以让某个Buff以附属Buff的形式挂载在其他Buff下，此时对象Buff才是这个附属Buff的主人Buff，

除此之外，附属Buff和普通Buff其实并没有什么特别大的区别，该怎么处理怎么处理，时间到了该结束就结束。

== 即效Buff ==
有时候，机制需要像真代码一样调用某个“函数”，即效Buff便是这种可供调用的“函数”，它们'''持续时间为0秒'''或者说'''没有持续时间'''，因此几乎只会触发“Buff开始时”事件中的伪代码——因此，当明日方舟的一个机制需要出现反复调用一段伪代码时，往往会尝试让Buff施加一个即效Buff。

许多技能实现与攻击特效大量使用即效Buff，因此导致{{异常效果|Buff可抵挡}}可能会意料外地阻止那些看上去不像Buff的一次性机制。

== 模式切换Buff ==
正常情况下，开启技能时切换模式该用技能使用的模式参数来处理，但实际不然。许多技能会在触发后获得一个Buff，技能结束时该Buff结束——而这个Buff'''在开始时会尝试将单位的模式切换为特定编号的模式'''，'''结束时将模式切换回来'''。这种便是模式切换Buff。

模式切换Buff相较于正常的技能的模式参数有两点优势：①代码方便，只需要对Buff的逻辑进行修改就能实现在特定情况下进入特定模式（例如第二次开启时使用特殊动画/特效）；②使用方便，任何类型的技能（哪怕是[[缄默德克萨斯|落地立刻死的被动技能]]）只需要绑定一个“技能期间获得Buff”就能使用，而原始的技能模式参数只在触发技能中使用。

通常情况，起飞干员依靠多个模式切换Buff来实现起飞的效果，即“常态→升空模式→滞空模式→降落模式”，也有一些起飞干员因为其“常态起飞”，完全不使用模式切换buff。

== 标记性Buff ==
标记性Buff本身'''没有效果'''，主要只是个“标记”，'''它的名字'''、'''它的来源'''、'''它的持有者'''就是它的全部机制，机制的实际处理往往在其他Buff或者选择器里<br>许多技能的机制都是靠标记性Buff实现的（例如“一技能期间”的标记、“处于技能范围内”标记等），因此站内若无必要不会标注出标记性Buff。

相对于“无必要”的便是“有必要”，像【无视雕伥减伤】这样的标记性Buff因机制特殊性，不作出说明很难解释清楚其机制

== 伪免疫Buff ==
主要用于实现{{特殊机制|停顿免疫}}和'''免疫水蚀'''的Buff。明日方舟因结构特殊性，只有异常效果可以被免疫，停顿、水蚀等效果本身就是一个Buff，无法被直接免疫，因此产生了这种专门用于免疫Buff的Buff。

此类Buff的本质是提供一个'''高叠加优先级的无效果同名Buff'''，因“同名效果取（优先级）最高”，新被施加的对应Buff（如停顿）会因为优先级不够高而被视为被“同名效果取最高”，从而达成让对应Buff无法生效的结构。

== 承载器Buff ==
一些Buff本身只有一半的效果或是无效果，其'''重要的只有它的黑板（变量库）'''，这被称为承载器Buff。它自己以及其他Buff会尝试读取/存入一些特定数据到它的黑板里，当承载器Buff被清除时，也就相当于这些数据被清除了。

那些记录“击杀过的敌人”、“部署次数”之类数据的机制会使用到承载器Buff，不过更多的是使用SharedBlackboard等其他方式实现。

== 存在时间Buff ==
一些Buff会让自己显示在sp条上“假装”自己是技能持续时间或者单位存在持续时间。让此类Buff会在结束时让单位离场或是离开某个状态。

傀儡师会利用存在时间Buff来表示自己的替身状态时间。

== 伪登场触发效果Buff ==
当单位登场时，会获得这个Buff——那也就是说，'''当这个Buff开始时，就是单位登场时'''。部分藏品机制中的“部署时”都是靠这个方式实现的。

傀儡师干员切换替身/切回本体时使用的逻辑可能会要求GlobalBuff、AuraAbility在失效后重新提供一遍此类Buff，导致再次触发“部署时”的效果。

正常的“登场触发”的Buff不该使用这套逻辑，也不可能出现这种情况。

== 伪离场触发效果Buff ==
与伪登场触发效果Buff类似<br>当单位离场时，这个永久的Buff也会被清除——那也就是说，'''当这个Buff结束时，就是单位离场时'''。部分藏品机制中的“撤退时”与“被击倒时”都是靠这个方式实现的。

问题在于傀儡师干员可能会清理这一类Buff，导致即使单位没有退场也会触发退场时的效果

正常的“离场触发”的Buff不该使用这套逻辑，也不可能出现这种情况。
