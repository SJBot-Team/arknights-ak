# **Cello（阿尔图罗）：
**

6星远程位干员，普攻造成单体法术伤害。

天赋1：在场时，全体敌方单位攻击力降低一定百分比。

天赋2：自身攻击范围内的敌方单位生命值低于一定百分比时，受到的伤害提升。

技能1：开启时，场上所有敌方单位移动速度降低。

技能2：开启时，自身攻击范围内所有敌方单位攻击力降低，场上所有敌方单位移动速度降低。

技能3：开启时，？？？，每次释放后下次释放需消耗的技力翻倍（有上限）。

# Mikami

4-5星近战位干员，职业疑似领主。

天赋1：技能开启时，攻击额外对目标造成停顿效果。

技能1：开启时，自身攻击力提升。

技能2：开启时，自身攻击力提升，攻击速度增加，远程攻击不再降低攻击倍率，普通攻击变为法术伤害。

# Phx

6星远程位干员，职业疑似炮手（普通攻击造成物理伤害，溅射半径1.0）

天赋1：编入队伍时，所有【深海猎人】干员最大生命值提升，攻击力提升。

天赋2：自身生命值处于一定区间内时，获得自身最大生命值一定百分比的自然生命回复。自身生命处于另一区间内时，获得自身最大生命值一定百分比的自然生命回复。（两个区间/效果可能重叠，例如血量低于50%时获得5%，血量低于25%时再获得5%）

技能1：没找到，应该是个通用技能

技能2：向前方发射弹道（应该类似ash3，但不会撞墙），击退沿途的敌人，并附加停顿效果。弹道碰撞半径0.75.

技能3：携带此技能时：自身技能未开启时不进行普通攻击，同时每秒受到自身最大生命值一定百分比的真实伤害。开启技能时：自身攻击力增加，攻击间隔发生变化，普通攻击同时攻击攻击范围内所有敌方单位，并附加停顿效果。

# Snwfox

3-5星远程位干员，职业疑似速射手。

天赋1：自身攻击空中单位时，攻击倍率提升。

技能1：开启时，自身攻击范围延长，攻击力提升。

技能2：没找到，有可能是3星干员只有1个技能，也有可能上面那个是2技能而1技能是通用技能。

# Ba

6星近战位干员，普通攻击造成单体物理伤害，不对空。

天赋1：阻挡一定数量的敌人时，自身sp回复速度加快。

天赋2：没找到，可能没做完。

技能1：开启时，自身攻击力提升，防御力提升，获得一定的法术闪避。

技能2：开启时，自身攻击力提升，获得一定的法术闪避，攻击为目标附加一定时间的沉默效果。

技能3：开启时，自身最大生命值提升，获得自身最大生命值一定百分比的自然生命回复，普通攻击可对空。

# Sancat

4-5星近战位干员，普通攻击造成单体物理伤害，不对空。

天赋1：自身攻击范围内所有敌方单位移动速度降低。

技能1：似乎是强力击。

技能2：普通攻击变为法术伤害。

# March

4-5星近战位干员，职业疑似剑豪。

天赋1：击杀时回复自身一定sp。

技能1：似乎是强力击，2连击的那种。

技能2：对一定范围内所有敌方单位造成一定法术伤害并施加停顿效果。

# Dashin

4-5星远程位干员，职业疑似扩散术士（普通攻击造成法术伤害，溅射半径1.0）

天赋1：对未被阻挡的单位造成伤害时，攻击倍率提升。

技能1：开启时，？？？，自身攻击模式变化。

技能2：开启时，？？？，自身攻击模式变化。
