[[分类:汇总]] 
'''技能'''是一个角色类实体单位可以携带入场的、可通过玩家交互触发的能力。
* 携带了技能的单位，点选时其右下角会出现技能图标。
* 一些情况下，技能也可以自动触发。
==技力需求==
绝大多数技能均需要一定的'''技力'''（SP）才能释放，由此可以按技力需求划分为以下三种类型：
* {{技能类型|自动回复}}<br>技力随时间自动回复；通常每秒回复1点技力。
* {{技能类型|攻击回复}}<br>技力在技能携带者每次攻击时回复1点技力。<br>※进行'''连击'''时，连击中的每次攻击都能获得技力，但近卫-剑豪分支特性为特别调整的例外，其二连击仅会回复1点技力。
* {{技能类型|受击回复}}<br>技力在技能携带者每次被攻击时回复1点技力。<br>※部分设置为“无法触发受击回复”的伤害不会触发该技力回复。

触发技能后，触发技能的单位将消耗相应的技力，随后在技能持续期间进入'''阻回'''（停止并阻止技力回复）。

绝大多数技能结束时，因技力在处理时被消耗，其技力将从0开始重新积累。

一般情况下，技力的最大储存量等同于该技能的技力需求。仅在携带者入场时，技能会预先充入“初始技力”以减少入场后至第一次发动技能的等待时间。
*技力需求与技力消耗并不完全等同；比如充能技能或者玛露希尔被特殊设置过技力消耗的技能。

如果一个技能没有技力需求，则其不需要技力即可触发。

对于技力，其最小单位为1点，'''不存在小数部分'''。
* 实际上，对于{{技能类型|自动回复}}技能，其会启用一个隐藏的“技力冷却槽”。
: “每秒回复1点技力”实际是技力冷却槽以1秒的时间完成冷却，并在每次完成冷却时补充1点技力 {{popup|内容=由于小数点精度问题，更精确的处理为：当前剩余冷却时间 < 10<sup>-5</sup>秒（0.1毫秒）时，视为冷却完成，增加1点SP，并使冷却槽的剩余冷却时间不断+1秒，直到当前剩余冷却时间 >= 10<sup>-5</sup>秒为止}}。在'''阻回'''状态或技力条已满时，保留剩余冷却时间，计时暂停。
: 对'''技力自然回复速度'''的修改实际上是对技力冷却槽的修改，而不改变回复速度。

==触发条件==
除了技力，技能还具有多种触发条件。
* {{技能类型|自动触发}}<br>技能在满足给定条件后自动触发。<br>通常情况下，'''没有白色边框'''的技能图标即为自动触发技能。<br>特例：白雪的二技能[[文件:技能 凝武.png|20px|link=白雪]]无框却为手动触发技能(内测时此为被动技能)。
* {{技能类型|手动触发}}<br>技能在满足给定条件后，需要玩家交互以触发。<br>与自动触发相反，通常情况下，'''有白色边框'''的技能图标即为手动触发技能。<br>特例：杰西卡的一技能[[文件:技能 强力击·β型.png|20px]]有框却为自动触发技能。
* {{技能类型|被动}}<br>技能直接生效，无需触发、释放；在部署时触发的一部分技能也会被写为被动技能。<br>此类技能一般为部署时生效/被动增益类的效果。

==特殊属性==
{{#widget:style|style=.charged img {filter:brightness(0.6) hue-rotate(308deg) saturate(1.5)} }}
* '''可充能'''
: 一些技能中存在“可充能X次”的描述，其实际效果为当前技力上限等于该技能技力需求的X倍，从而实现可连续释放该技能的效果。
: 查看角色详情时，技能按钮左上角会出现圆点显示可释放次数；如果该技能为自动触发，持有者模型顶部也会显示{{mdi|autorenew}}符号，其中会记录该技能的可释放次数。
: 部分可充能技能在技力达到上限后（即充能次数达到上限）会立刻产生额外效果，如立刻释放一次、攻击范围变化、攻击动作变化等。
: ※某些情况下，可充能次数会多次消耗（例如[[重岳]]的一技能）。
: ※当持有者的技力流失时，充能次数也会实时降低（但因达到上限产生的额外效果会依然生效）。
:* <div class="charged" style="display:flex;align-items: center;">特殊：[[文件:图标 技能 启动.png|30px]]{{术语|ba.charged|'''蓄力'''|术语=蓄力}}</div>自干员[[卡涅利安]]实装起的一种技能/技力计算机制，实际效果上是'''可充能'''的变种版本。<br>其实际实现为可充能2次，但仅在满充能释放时可触发额外的“蓄力效果”（此时技能开启标记将变为橙红色）。<br>※一般情况下，可蓄力的技能无论何时发动，都将消耗所有技力。
* '''弹药'''
: 自干员[[灰烬]]实装起的一种技能消耗计算机制。此类技能会存在“装有X发弹药，打完后结束”的描述。
: 此类技能在开启后不计算持续时间，而是替换为该技能的'''弹药数'''，而技能效果会消耗一定量的弹药；当下次普通攻击时弹药不高于0，则会退出技能状态。
: ※消耗弹药时不受当前弹药数限制，必定消耗相应数额的弹药，此时可能出现“负数弹药”的情况，并因为上述条件而退出技能。
: ※弹药类技能的图标在大多数情况下会获得一个'''子弹角标'''，首个通用款式首次出现于[[假日威龙陈]]的技能图标中（[[文件:技能 “假日风暴”.png|50px|link=假日威龙陈]]）。<br>但有少部分干员的技能（如[[熔泉]]的“便携破城矢”、[[极光]]的“人工降雪”）符合该条件但没有子弹角标，可能是官方遗漏。
* <div style="display:flex;align-items: center;">[[文件:图标 技能 关闭.png|25px]]'''可关闭（可随时主动关闭）'''</div>
: 自干员[[灰烬]]实装起的一种让技能'''二次触发'''的机制，允许玩家下达“关闭技能”的指令。
: 此类技能接收到玩家二次触发的指令时，通常会立刻终止当前技能效果（称为主动关闭），也可能产生关闭以外的一些其他的效果。
: 存在该机制的技能在技能期间点选干员后，技能按钮会叠加“STOP”图标，点击后即可主动关闭技能。
: ※由于实现上为二次触发，干员处于任何无法触发技能的状态时将同样无法主动关闭技能，除非有特殊的调整（如[[缇缇]]的二技能）。
:* 特殊：{{特殊机制|弹药倾泻|名称='''弹药倾泻'''}}<br>自干员[[号角]]实装起的一种替换弹药类技能“主动关闭”的二次触发效果，其文本以“主动关闭时”描述关闭后的效果。<br>实际上是二次触发时额外检查是否满足弹药倾泻的发动条件，并在满足时以一轮“弹药倾泻”替换技能的主动关闭。
* '''{{术语|ba.overdrive|过载}}'''
: 自干员[[洛洛]]和[[号角]]实装起的一种技能计算机制。
: 此类技能持续经过一半时，将会进入过载状态，此时技能持续条将变为红色，并触发额外的“过载效果”。
: ※此类技能的持续条也只会显示一半的技能持续而非完整的持续条。
: ※对于拥有'''弹药'''的技能，其过载触发条件等同于“弹药剩余量降至初始弹药量的一半时”。
* <div style="display:flex;align-items: center;">[[文件:图标 技能 装备应变.png|25px]]'''装备应变'''</div>
: 自干员[[哈蒂娅]]实装起的一种特殊的技能触发机制兼二次触发机制，代表该技能存在依玩家指令选择的额外效果。
: 存在该机制的情况下，点选干员后会在技能按钮右上角将出现专门的“MODIFY”按钮，点击后将以装备应变的形式触发技能，或在技能期间尝试激活装备应变效果。
: 使用装备应变效果通常需要消耗部署费用。
: ※直接依靠装备应变开启技能时为特殊的技能触发；在技能期间使用装备应变时则为技能二次触发。

==敌人的技能与其spdata==
实体类型为敌人的单位有时也会携带技能，其在运作时大多数情况依照{{技能类型|冷却时间}}（也即 Cooldown / CD）进行触发。
* 正常情况下，所有冷却技能会同时各自进行CD和释放判定，并且会有一个“初始CD”以提前/推迟首次释放的时间点（效果和干员部署后的“初始技力”相似）。
: 如果有多个技能完成了CD，则会根据预先设定的优先级调整释放时间。相同优先级的情况下会随机进行释放。
技能的<code>spdata</code>不为<code>null</code>时意味着其具有技力相关的设定，包括上述提到的技力上限和技力回复需求。

但与角色类实体不同的是，敌人类实体具有多种技能，此时如果技能有技力需求，则将扣除对应的技力来释放这个技能，其作用方式更接近于RPG游戏中随取随用的“蓝条”。
* 例如常见的敌方“弹药”，其本质是拥有X点技力；每次发动对应的“弹药攻击”时，实际为消耗1技力释放技能。

有时候敌人实体的技力条也会用于一些奇妙用途，比如[[反巫术变位炸弹]]的速度指示器。
*注意：敌人的技能在大多数情况并不属于普通攻击（依赖普通攻击的除外），通过技能进行的攻击将不会受到战栗/麻痹的影响。

==干员技能的大体归类==
{{主观内容}}
{{cbox2|lv=2|text=本页面的部分结论在适用实际情况时，部分技能的图标会存在复合定位或不符合定位的情况，在此不予列举。<br>本页面内容'''不考虑联动干员的技能图标'''，因为其通常会以联动干员的出处作品而做出明显差异化的视觉设计。}}
通常情况下，一个干员所使用的技能会具有一个代表图标，该图标通常包含下列固定元素：
* 白色边框（见上文[[#触发条件|触发条件]]）；
* 白色主视觉图案，通常会反映该干员自身和该技能在设定（角色塑造）上的设计风格；
* '''背景的衬底图案及其颜色；'''
* 渐变黑灰色背景。
其中衬底图案及其颜色在多个技能中有出现，可以此综合分析，得到如下规律。
===背景图案颜色===
根据技能图标背景图案颜色的不同，目前在游戏中有以下五种图案颜色。模组图标的底色也大致分为此类。
* '''{{color|red|红：攻击型}}'''
: 通常提供更强的攻击性能或模式。
* '''{{color|#ffcc00|黄：防护型}}'''
: 通常提供更强的生存性能或模式。
:* 不局限于防御力与法术抗性，如[[文件:技能 环境伪装.png|45px|link=守林人]]增加了攻击力属性却带来了更利于生存的'''隐匿'''效果。
* '''{{color|#2aa6e0|蓝：再生型}}'''
: 通常提供更强的治疗性能或模式。
* '''{{color|#90c21d|绿：战术支援型}}'''
: 提供战术支援的技能，以提供部署费用居多。
:* 目前该型技能不与部署费用相关的只有三个：[[文件:技能 圣域.png|45px|link=夜莺]][[文件:技能 深度治疗.png|45px|link=苏苏洛]][[文件:技能 鞭策.png|45px|link=杜宾]]<br>但前两者为提供法术闪避（120秒CD）/强力医疗保人不死（且只能用两次），后者结合天赋提升全场三星干员的攻击力且内测期间此技能可以提供部署费用，因此推测归入此类。
* '''{{color|#707070|灰：其它型}}'''
: 不符合上述四种定位任何之一时便会划分至该类型。
: 通常意味着该技能没有额外的伤害，或不以造成伤害为主要目的，以常驻的被动效果或特殊的支援性能为主。
